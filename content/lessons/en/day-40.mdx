## Intro

<En>
Postman is great for manual exploration, but automated API tests run in Python. The `requests` library is Python's go-to HTTP client — simple, readable, and powerful. Every API testing framework you'll encounter (pytest + requests, API clients, SDK wrappers) uses `requests` under the hood. Today you make your first real HTTP calls from Python.
</En>
<Vi>
Postman rất tốt để khám phá thủ công, nhưng các API test tự động chạy trong Python. Thư viện `requests` là HTTP client hàng đầu của Python — đơn giản, dễ đọc và mạnh mẽ. Mọi framework kiểm thử API bạn sẽ gặp đều dùng `requests` bên dưới. Hôm nay bạn thực hiện các cuộc gọi HTTP thực sự đầu tiên từ Python.
</Vi>

## Concept

<En>
**Install:**
```bash
pip install requests
```

**Basic usage:**
```python
import requests

response = requests.get("https://api.example.com/users")
response = requests.post("https://api.example.com/users", json={"email": "a@b.com"})
response = requests.put("https://api.example.com/users/1", json={"name": "Alice"})
response = requests.patch("https://api.example.com/users/1", json={"name": "Alice"})
response = requests.delete("https://api.example.com/users/1")
```

**The Response object:**

| Property/Method | What it gives you |
|-----------------|------------------|
| `response.status_code` | Integer status code (200, 404, etc.) |
| `response.json()` | Parse response body as dict/list |
| `response.text` | Response body as string |
| `response.headers` | Dict of response headers |
| `response.ok` | `True` if status < 400 |
| `response.raise_for_status()` | Raise `HTTPError` if status >= 400 |

**Sending data:**
- `json=` — serialises dict to JSON, sets Content-Type automatically
- `params=` — query parameters (`?key=value&key2=value2`)
- `headers=` — custom headers dict
- `data=` — form-encoded body (not JSON)

**Using a Session (recommended):**
```python
session = requests.Session()
session.headers.update({"Authorization": "Bearer abc123"})
# All requests via session share headers, cookies, connection pool
```
</En>

## Code / Demo

```python
# Real HTTP calls to JSONPlaceholder — a free, public REST API for testing
import requests

BASE_URL = "https://jsonplaceholder.typicode.com"

# --- GET a resource ---
response = requests.get(f"{BASE_URL}/posts/1")
assert response.status_code == 200
post = response.json()
print(f"GET post: id={post['id']}, title={post['title'][:30]}...")

# --- Assert types and fields ---
assert isinstance(post["id"], int)
assert isinstance(post["title"], str)
assert post["id"] == 1

# --- POST to create ---
new_post = {"title": "My Test Post", "body": "Content here", "userId": 1}
response = requests.post(f"{BASE_URL}/posts", json=new_post)
assert response.status_code == 201
created = response.json()
assert "id" in created
assert created["title"] == "My Test Post"
print(f"Created post id: {created['id']}")

# --- GET a list with query params ---
response = requests.get(f"{BASE_URL}/posts", params={"userId": 1, "_limit": 3})
assert response.status_code == 200
posts = response.json()
assert isinstance(posts, list)
assert len(posts) <= 3
print(f"Got {len(posts)} posts for userId=1")

# --- DELETE ---
response = requests.delete(f"{BASE_URL}/posts/1")
assert response.status_code == 200  # JSONPlaceholder returns 200 for delete

# --- Using a Session ---
session = requests.Session()
session.headers.update({
    "Content-Type": "application/json",
    "X-Test-Run": "automation-phase4"
})

response = session.get(f"{BASE_URL}/users/1")
assert response.status_code == 200
user = response.json()
assert "email" in user
print(f"User: {user['name']} ({user['email']})")

# --- raise_for_status pattern ---
try:
    response = requests.get(f"{BASE_URL}/posts/99999")
    response.raise_for_status()
except requests.exceptions.HTTPError as e:
    print(f"HTTP error: {e}")

print("All requests tests passed!")
```
