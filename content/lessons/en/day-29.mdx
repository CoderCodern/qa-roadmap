## Intro

<En>
Imagine you have 30 tests that all log in before doing their thing. The login form has an email field, a password field, and a submit button. One day the developer renames the button from "Login" to "Sign in". Now all 30 tests break — you have to find and update 30 different locators scattered across 30 files.

The **Page Object Model (POM)** solves this. Instead of writing locators directly in test files, you create a Python class that represents a page (or component) and encapsulates all its locators and actions. The 30 tests all call `login_page.login(email, password)` — and when the button text changes, you fix it in exactly one place.

POM is the single most impactful design pattern in UI test automation.
</En>
<Vi>
Hãy tưởng tượng bạn có 30 test đều cần đăng nhập trước khi thực hiện hành động. Form đăng nhập có trường email, trường mật khẩu và nút submit. Một ngày, developer đổi tên nút từ "Login" thành "Sign in". Bây giờ tất cả 30 test đều hỏng — bạn phải tìm và cập nhật 30 locator khác nhau rải rác trong 30 file.

**Page Object Model (POM)** giải quyết vấn đề này. Thay vì viết locator trực tiếp trong file test, bạn tạo một class Python đại diện cho một trang (hoặc component) và đóng gói tất cả locator và hành động của nó. 30 test đều gọi `login_page.login(email, password)` — và khi text nút thay đổi, bạn sửa ở đúng một chỗ.

POM là design pattern có tác động lớn nhất trong tự động hoá UI.
</Vi>

## Concept

<En>
**The core idea — separation of concerns:**

```
Without POM                         With POM
─────────────────────────────────   ─────────────────────────────────────
test_login.py                       pages/login_page.py
  page.fill("#email", "a@b.com")      class LoginPage:
  page.fill("#pass", "pw")              def login(self, email, pw):
  page.click("button[Login]")             self.email.fill(email)
  assert "dashboard" in page.url          self.password.fill(pw)
                                          self.submit_btn.click()
test_checkout.py
  page.fill("#email", "a@b.com")    test_login.py
  page.fill("#pass", "pw")            login_page.login("a@b.com", "pw")
  page.click("button[Login]")         expect(page).to_have_url(".../dashboard")
  # ... checkout steps ...
                                    test_checkout.py
                                      login_page.login("a@b.com", "pw")
                                      # ... checkout steps ...
```

**Rules of a good Page Object:**

1. **Never assert in a Page Object** — a PO is a reusable action layer; let the test decide what to assert.
2. **Return `self` or another Page Object** from action methods — enables method chaining and represents navigation.
3. **Keep locators private** — the test should call `page_object.login(...)`, not `page_object.email_input.fill(...)`.
4. **One class per page (or major component)** — LoginPage, DashboardPage, CartPage, etc.
5. **Initialise locators in `__init__`** — so they're defined once and reused.

**Anatomy of a Page Object:**

```python
from playwright.sync_api import Page, Locator

class LoginPage:
    # URL constant — good practice
    URL = "/auth/login"

    def __init__(self, page: Page):
        self.page = page
        # ── Locators defined once ────────────────────────────────
        self.email_input: Locator = page.get_by_label("Email")
        self.password_input: Locator = page.get_by_label("Password")
        self.login_button: Locator = page.get_by_role("button", name="Login")
        self.error_message: Locator = page.locator(".alert-danger")

    # ── Actions ──────────────────────────────────────────────────
    def navigate(self) -> "LoginPage":
        self.page.goto(self.URL)
        return self

    def login(self, email: str, password: str) -> "LoginPage":
        self.email_input.fill(email)
        self.password_input.fill(password)
        self.login_button.click()
        return self  # or return DashboardPage(self.page) after redirect

    def login_and_go_to_dashboard(self, email: str, password: str) -> "DashboardPage":
        self.email_input.fill(email)
        self.password_input.fill(password)
        self.login_button.click()
        return DashboardPage(self.page)  # navigate to next page
```

**Using the Page Object in tests:**

```python
def test_successful_login(page: Page):
    login_page = LoginPage(page)
    login_page.navigate()
    login_page.login("user@example.com", "password123")
    expect(page).to_have_url("**/dashboard")

# Method chaining style:
def test_login_chained(page: Page):
    LoginPage(page).navigate().login("user@example.com", "password123")
    expect(page).to_have_url("**/dashboard")
```

**Shared login fixture (pytest best practice):**
```python
# conftest.py
@pytest.fixture
def logged_in_page(page):
    """Pre-authenticated page — use in tests that need to skip login."""
    LoginPage(page).navigate().login("customer@example.com", "welcome01")
    return page
```
</En>
<Vi>
**Ý tưởng cốt lõi — phân tách mối quan tâm:**

Không có POM: locator rải rác trong từng file test — khi UI thay đổi, phải sửa nhiều nơi.
Có POM: tất cả locator và hành động nằm trong class — khi UI thay đổi, chỉ sửa một nơi.

**Quy tắc của Page Object tốt:**
1. **Không bao giờ assert trong Page Object** — PO là lớp hành động tái sử dụng
2. **Trả về `self` hoặc Page Object khác** — cho phép method chaining
3. **Giữ locator private** — test chỉ gọi action, không trực tiếp dùng locator
4. **Một class mỗi trang** — LoginPage, DashboardPage, CartPage...
5. **Khởi tạo locator trong `__init__`** — định nghĩa một lần, dùng nhiều lần

**Cấu trúc của Page Object:**
```python
class LoginPage:
    def __init__(self, page: Page):
        self.page = page
        self.email_input = page.get_by_label("Email")
        self.password_input = page.get_by_label("Password")
        self.login_button = page.get_by_role("button", name="Login")

    def navigate(self):
        self.page.goto("/auth/login")
        return self

    def login(self, email: str, password: str):
        self.email_input.fill(email)
        self.password_input.fill(password)
        self.login_button.click()
        return self
```

```python
# pages/login_page.py
from playwright.sync_api import Page, Locator

class LoginPage:
    """Page Object for https://practicesoftwaretesting.com/auth/login"""

    URL = "https://practicesoftwaretesting.com/auth/login"

    def __init__(self, page: Page) -> None:
        self.page = page
        # Locators — defined once here
        self.email_input: Locator = page.get_by_label("Email")
        self.password_input: Locator = page.get_by_label("Password")
        self.login_button: Locator = page.get_by_role("button", name="Login")
        self.error_alert: Locator = page.locator(".alert-danger")

    def navigate(self) -> "LoginPage":
        self.page.goto(self.URL)
        return self

    def fill_email(self, email: str) -> "LoginPage":
        self.email_input.fill(email)
        return self

    def fill_password(self, password: str) -> "LoginPage":
        self.password_input.fill(password)
        return self

    def submit(self) -> "LoginPage":
        self.login_button.click()
        return self

    def login(self, email: str, password: str) -> "LoginPage":
        """Convenience method: fill both fields and submit."""
        self.fill_email(email)
        self.fill_password(password)
        self.submit()
        return self
```

```python
# tests/test_login_with_pom.py
# Run with: pytest tests/test_login_with_pom.py -v
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), ".."))

from playwright.sync_api import Page, expect
from pages.login_page import LoginPage

BASE = "https://practicesoftwaretesting.com"
VALID_EMAIL = "customer@practicesoftwaretesting.com"
VALID_PASSWORD = "welcome01"

def test_valid_login_with_pom(page: Page):
    """Valid credentials → redirect to account page."""
    LoginPage(page).navigate().login(VALID_EMAIL, VALID_PASSWORD)
    expect(page).to_have_url(f"{BASE}/account")

def test_invalid_login_shows_error(page: Page):
    """Invalid credentials → error message visible."""
    login_page = LoginPage(page)
    login_page.navigate()
    login_page.login("wrong@example.com", "wrongpassword")
    expect(login_page.error_alert).to_be_visible()

def test_empty_email_shows_validation(page: Page):
    """Empty email → form should not submit (or show error)."""
    login_page = LoginPage(page)
    login_page.navigate()
    login_page.fill_password(VALID_PASSWORD)
    login_page.submit()
    # Either still on login page or validation message
    assert "login" in page.url or login_page.error_alert.is_visible()
```
