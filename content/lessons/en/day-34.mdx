## Intro

<En>
Writing tests on your laptop is the first step. But tests only provide real value when they run **automatically** — on every push, every pull request, every merge. That's what **Continuous Integration (CI)** means: a pipeline that runs your tests without you having to remember to trigger them.

**GitHub Actions** is the most widely-used CI platform for open-source and small-to-medium teams. It's free for public repos, deeply integrated with GitHub, and requires zero setup beyond adding one YAML file to your project. Today you write that file and watch your Playwright tests run in the cloud.
</En>
<Vi>
Viết test trên laptop của bạn là bước đầu tiên. Nhưng test chỉ thực sự có giá trị khi chúng chạy **tự động** — mỗi lần push, mỗi lần pull request, mỗi lần merge. Đó là ý nghĩa của **Continuous Integration (CI)**: một pipeline chạy test của bạn mà không cần bạn nhớ kích hoạt chúng.

**GitHub Actions** là nền tảng CI được sử dụng rộng rãi nhất cho các nhóm nhỏ và vừa. Miễn phí cho repo công khai, tích hợp sâu với GitHub và không cần thiết lập gì ngoài việc thêm một file YAML vào dự án. Hôm nay bạn viết file đó và xem Playwright test của mình chạy trên cloud.
</Vi>

## Concept

<En>
**How GitHub Actions works:**

1. You push code to GitHub
2. GitHub detects the push and reads `.github/workflows/*.yml`
3. GitHub spins up a virtual machine (Ubuntu by default)
4. Your workflow installs dependencies, runs tests, and reports results
5. GitHub marks the commit ✅ (all pass) or ❌ (any fail)

**Key YAML concepts:**

```yaml
# A workflow file has:
name: My Workflow     # display name in the Actions tab

on:                   # when to trigger
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:                 # one or more jobs
  test:               # job name (arbitrary)
    runs-on: ubuntu-latest   # VM type

    steps:            # sequential steps in the job
      - name: Step name
        uses: actions/checkout@v4   # run a pre-built action
      - name: Another step
        run: echo "Hello"           # run a shell command
```

**The minimal Playwright CI workflow:**

```yaml
# .github/workflows/playwright.yml
name: Playwright Tests

on:
  push:
    branches: [main, dev]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install Python dependencies
        run: pip install pytest playwright pytest-playwright

      - name: Install Playwright browsers
        run: playwright install --with-deps chromium

      - name: Run Playwright tests
        run: pytest tests/ -v --tb=short
```

**Uploading test artifacts (screenshots, traces, reports):**
```yaml
      - name: Run Playwright tests
        run: pytest tests/ -v --screenshot=only-on-failure --output=test-results
        continue-on-error: true    # don't stop; upload artifacts even on failure

      - name: Upload test results
        uses: actions/upload-artifact@v4
        if: always()               # upload even when tests fail
        with:
          name: playwright-results
          path: test-results/
          retention-days: 7
```

**Using environment variables and secrets:**
```yaml
      - name: Run tests
        env:
          BASE_URL: https://staging.example.com
          TEST_PASSWORD: ${{ secrets.TEST_PASSWORD }}  # set in repo Settings → Secrets
        run: pytest tests/ -v
```

**Matrix strategy — test across multiple browsers:**
```yaml
    strategy:
      matrix:
        browser: [chromium, firefox, webkit]
    steps:
      - name: Run tests on ${{ matrix.browser }}
        run: pytest tests/ --browser ${{ matrix.browser }} -v
```

**Caching dependencies for speed:**
```yaml
      - name: Cache pip packages
        uses: actions/cache@v4
        with:
          path: ~/.cache/pip
          key: ${{ runner.os }}-pip-${{ hashFiles('requirements.txt') }}

      - name: Cache Playwright browsers
        uses: actions/cache@v4
        with:
          path: ~/.cache/ms-playwright
          key: ${{ runner.os }}-playwright-${{ hashFiles('requirements.txt') }}
```
</En>
<Vi>
**Cách GitHub Actions hoạt động:**
1. Bạn push code lên GitHub
2. GitHub phát hiện push và đọc `.github/workflows/*.yml`

## Code / Demo

<En>

**Part 1 — The complete production-ready workflow**

</En>
<Vi>

**Phần 1 — Workflow hoàn chỉnh sẵn sàng cho production**

</Vi>

```yaml
# .github/workflows/playwright.yml
# Save this file at: .github/workflows/playwright.yml
name: Playwright UI Tests

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]
  # Allow manual triggering from the Actions tab
  workflow_dispatch:

jobs:
  playwright-tests:
    name: Run Playwright Tests
    runs-on: ubuntu-latest
    timeout-minutes: 30    # kill the job if it hangs

    steps:
      # Step 1: Get the code
      - name: Checkout repository
        uses: actions/checkout@v4

      # Step 2: Set up Python
      - name: Set up Python 3.12
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: pip             # cache pip packages between runs

      # Step 3: Install Python dependencies
      - name: Install dependencies
        run: |
          pip install --upgrade pip
          pip install pytest playwright pytest-playwright pytest-html

      # Step 4: Install browser binaries (only Chromium for CI)
      - name: Install Playwright browsers
        run: playwright install --with-deps chromium
        # --with-deps also installs OS-level dependencies (fonts, libs)
        # required on bare Ubuntu runners

      # Step 5: Run the tests
      - name: Run Playwright tests
        run: |
          pytest tests/ \
            --browser chromium \
            --headless \
            -v \
            --tb=short \
            --screenshot=only-on-failure \
            --tracing=retain-on-failure \
            --output=test-results \
            --html=test-results/report.html \
            --self-contained-html
        # continue even if tests fail — so we can upload artifacts
        continue-on-error: true

      # Step 6: Upload test artifacts (screenshots, traces, HTML report)
      - name: Upload test results
        uses: actions/upload-artifact@v4
        if: always()    # run this step even if previous steps failed
        with:
          name: playwright-test-results-${{ github.run_id }}
          path: test-results/
          retention-days: 14   # keep artifacts for 14 days

      # Step 7: Fail the job if tests failed (after uploading artifacts)
      - name: Check test results
        if: always()
        run: |
          if [ -f "test-results/.last-run.json" ]; then
            python -c "
          import json
          with open('test-results/.last-run.json') as f:
              data = json.load(f)
          failed = data.get('failed', 0)
          if failed > 0:
              print(f'{failed} test(s) failed')
              exit(1)
            "
          fi
```

```python
# conftest.py — CI-aware configuration
import pytest
import os

# Read CI environment variable (GitHub Actions sets CI=true automatically)
IS_CI = os.environ.get("CI", "false").lower() == "true"

@pytest.fixture(scope="session")
def browser_context_args(browser_context_args):
    """Override browser context defaults — stricter in CI."""
    return {
        **browser_context_args,
        "viewport": {"width": 1280, "height": 720},
        # In CI, use a fixed locale to avoid date/time formatting differences
        "locale": "en-US",
        "timezone_id": "America/New_York",
    }

def pytest_configure(config):
    """Print environment info at test start."""
    print(f"\nRunning in CI: {IS_CI}")
    print(f"Base URL: {os.environ.get('BASE_URL', 'not set')}")
```
