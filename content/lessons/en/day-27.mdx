## Intro

<En>
When a test fails in CI at 2am, you can't be there to watch what happened. **Screenshots** and **trace files** are the time machine that lets you reconstruct exactly what the browser saw at the moment of failure.

Screenshots capture a single frame — what was on screen right when you called the method. Traces record everything: every action, every network request, every DOM snapshot, and every screenshot — in a single compressed file you can open in Playwright's interactive Trace Viewer. Together, these tools transform debugging from guesswork to forensics.
</En>
<Vi>
Khi test thất bại trong CI lúc 2 giờ sáng, bạn không thể ở đó để xem điều gì đã xảy ra. **Screenshots** và **trace file** là cỗ máy thời gian cho phép bạn tái tạo chính xác những gì trình duyệt đã thấy tại thời điểm thất bại.

Screenshot chụp một khung đơn — những gì hiển thị trên màn hình ngay khi bạn gọi phương thức. Trace ghi lại mọi thứ: mọi hành động, mọi network request, mọi DOM snapshot và mọi screenshot — trong một file nén duy nhất bạn có thể mở trong Trace Viewer tương tác của Playwright.
</Vi>

## Concept

<En>
**Screenshots — three modes:**

```python
# 1. Full page screenshot (captures content below the fold too)
page.screenshot(path="full_page.png", full_page=True)

# 2. Visible viewport only (default)
page.screenshot(path="viewport.png")

# 3. Single element screenshot
page.locator(".product-card").screenshot(path="card.png")

# Useful options:
page.screenshot(
    path="screenshot.png",
    full_page=True,
    clip={"x": 0, "y": 0, "width": 800, "height": 400},  # crop region
    type="jpeg",   # "png" (default) or "jpeg"
    quality=80,    # JPEG quality 0-100
    omit_background=True,  # transparent background (PNG only)
)
```

**Videos — record the entire test:**
```python
context = browser.new_context(record_video_dir="videos/")
# ... run your test ...
context.close()  # video is saved on context.close()
```

**Traces — the most powerful debugging tool:**

A trace file captures:
- All Playwright actions with timestamps
- Screenshots before and after each action
- Network requests and responses
- Console messages
- DOM snapshots at every step

```python
# Start tracing before the test
context.tracing.start(screenshots=True, snapshots=True, sources=True)

# ... run your test ...

# Stop and save the trace
context.tracing.stop(path="trace.zip")

# Open in Trace Viewer (run this in terminal, not in Python):
# playwright show-trace trace.zip
```

**pytest-playwright automatic on-failure capture:**
Add this to `conftest.py` to auto-capture screenshots and traces when a test fails:

```python
# conftest.py
import pytest
from playwright.sync_api import Page

@pytest.fixture(scope="function", autouse=True)
def capture_on_failure(request, page: Page):
    yield  # test runs here
    # This runs AFTER the test
    if request.node.rep_call.failed:
        test_name = request.node.name
        page.screenshot(path=f"screenshots/{test_name}.png", full_page=True)
```

**Or use pytest-playwright's built-in screenshot option:**
```bash
# Take screenshot on failure automatically
pytest tests/ --screenshot=only-on-failure --output=test-results

# Always take screenshots
pytest tests/ --screenshot=on

# Record video
pytest tests/ --video=retain-on-failure

# Record trace
pytest tests/ --tracing=retain-on-failure
```
</En>

```python
# demo_screenshots.py

# Creates: homepage.png, card.png, after_search.png
from playwright.sync_api import sync_playwright
import os

os.makedirs("screenshots", exist_ok=True)

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page(viewport={"width": 1280, "height": 720})

    # 1. Capture the homepage
    page.goto("https://practicesoftwaretesting.com")
    page.wait_for_load_state("networkidle")
    page.screenshot(path="screenshots/homepage.png", full_page=True)
    print("Saved: screenshots/homepage.png")

    # 2. Capture a single element
    first_card = page.locator(".card").first
    first_card.screenshot(path="screenshots/first_product_card.png")
    print("Saved: screenshots/first_product_card.png")

    # 3. Capture after an action
    search = page.get_by_role("textbox", name="Search")
    search.fill("Hammer")
    search.press("Enter")
    page.wait_for_load_state("networkidle")
    page.screenshot(path="screenshots/search_results.png")
    print("Saved: screenshots/search_results.png")

    browser.close()
    print("\nAll screenshots saved to ./screenshots/")
```

```python
# demo_trace.py

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    context = browser.new_context()

    # Start recording everything
    context.tracing.start(
        screenshots=True,   # capture screenshot on each action
        snapshots=True,     # capture DOM snapshot on each action
        sources=True,       # include source files in the trace
    )

    page = context.new_page()

    # Run the test scenario
    page.goto("https://practicesoftwaretesting.com/auth/login")
    page.get_by_label("Email").fill("customer@practicesoftwaretesting.com")
    page.get_by_label("Password").fill("welcome01")
    page.get_by_role("button", name="Login").click()
    page.wait_for_url("**/account")

    # Stop and save the trace
    context.tracing.stop(path="trace.zip")
    context.close()
    browser.close()

print("Trace saved → trace.zip")
print("Open it with: playwright show-trace trace.zip")
print("\nIn the Trace Viewer you can:")
print("  - Click any action to see before/after screenshots")
print("  - Inspect network requests at each step")
print("  - See the DOM state at any point in time")
```

**Part 3 — conftest.py: automatic screenshot on failure**

</En>
<Vi>

**Phần 3 — conftest.py: tự động chụp màn hình khi test thất bại**

</Vi>

```python
# conftest.py — place at project root
# Automatically saves screenshot + trace when any test fails
import pytest
import os
from pathlib import Path

@pytest.fixture(autouse=True)
def trace_test(context, request):
    """Start tracing before every test; save trace on failure."""
    context.tracing.start(screenshots=True, snapshots=True)
    yield
    if request.node.rep_call and request.node.rep_call.failed:
        test_name = request.node.name.replace("/", "_")
        Path("test-artifacts").mkdir(exist_ok=True)
        context.tracing.stop(path=f"test-artifacts/{test_name}-trace.zip")
    else:
        context.tracing.stop()  # discard trace on success

@pytest.hookimpl(hookwrapper=True)
def pytest_runtest_makereport(item, call):
    """Attach test result to the request object for access in fixtures."""
    outcome = yield
    rep = outcome.get_result()
    setattr(item, "rep_" + rep.when, rep)
```
