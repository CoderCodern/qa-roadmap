## Intro

<En>
Test automation frequently reads from and writes to files: loading test data from JSON fixtures, saving screenshots, writing test reports, and reading configuration files. Python makes file I/O simple, and the built-in `json` module handles serialisation and deserialisation automatically. Today you will learn the patterns used in real test codebases.
</En>
<Vi>
Tự động hoá test thường xuyên đọc và ghi file: tải dữ liệu test từ JSON fixture, lưu ảnh chụp màn hình, ghi báo cáo test và đọc file cấu hình. Python làm cho I/O file đơn giản, và module `json` tích hợp xử lý tuần tự hoá và giải tuần tự hoá tự động. Hôm nay bạn sẽ học các mẫu được dùng trong các codebase test thực tế.
</Vi>

## Concept

<En>
**Reading and writing files — always use `with`:**
```python
# Writing
with open("output.txt", "w") as f:
    f.write("content")

# Reading
with open("input.txt", "r") as f:
    content = f.read()      # entire file as string
    lines = f.readlines()   # list of lines
```

The `with` statement (context manager) guarantees the file is closed even if an exception occurs. Never call `open()` without `with`.

**JSON operations:**

| Task | Code |
|------|------|
| Parse string → dict | `json.loads(string)` |
| Serialize dict → string | `json.dumps(data, indent=2)` |
| Read JSON file | `json.load(file_object)` |
| Write JSON file | `json.dump(data, file_object, indent=2)` |

**File modes:**
- `"r"` — read (default)
- `"w"` — write (overwrites)
- `"a"` — append
- `"r+"` — read and write

**`pathlib.Path`** — the modern way to work with paths:
```python
from pathlib import Path
fixtures = Path("tests/fixtures")
data = json.loads((fixtures / "users.json").read_text())
```

**Common QA patterns:**
- Load a JSON fixture file at the start of a test
- Write test results to a JSON summary file
- Read configuration from an environment-specific JSON file
</En>
<Vi>
**Đọc và ghi file — luôn dùng `with`:**
```python
# Ghi
with open("output.txt", "w") as f:
    f.write("content")

# Đọc
with open("input.txt", "r") as f:
    content = f.read()      # toàn bộ file dưới dạng chuỗi
    lines = f.readlines()   # danh sách các dòng
```

Câu lệnh `with` (context manager) đảm bảo file được đóng ngay cả khi có ngoại lệ xảy ra. Đừng bao giờ gọi `open()` mà không dùng `with`.

**Các thao tác JSON:**

| Tác vụ | Code |
|------|------|
| Phân tích chuỗi → dict | `json.loads(string)` |
| Tuần tự hoá dict → chuỗi | `json.dumps(data, indent=2)` |
| Đọc file JSON | `json.load(file_object)` |
| Ghi file JSON | `json.dump(data, file_object, indent=2)` |

**`pathlib.Path`** — cách hiện đại để làm việc với đường dẫn:
```python
from pathlib import Path
fixtures = Path("tests/fixtures")
data = json.loads((fixtures / "users.json").read_text())
```
</Vi>

## Code / Demo

**Pattern 1 — Read and write text files with `with open()`**

<En>Always open files with the `with` statement. It automatically closes the file when the block exits — even if an exception is raised. Never use `f = open(...)` without a `with`.</En>
<Vi>Luôn mở file bằng câu lệnh `with`. Nó tự động đóng file khi khối kết thúc — ngay cả khi có ngoại lệ. Đừng bao giờ dùng `f = open(...)` mà không có `with`.</Vi>

<CodePlayground code={`
from pathlib import Path

log_path = Path("test_run.log")

# Write — mode "w" creates or overwrites
with open(log_path, "w", encoding="utf-8") as f:
    f.write("TC-001 PASS\\n")
    f.write("TC-002 PASS\\n")
    f.write("TC-003 FAIL\\n")
print(f"Wrote log to {log_path}")

# Read entire file as one string
with open(log_path, "r", encoding="utf-8") as f:
    content = f.read()
assert "TC-001 PASS" in content
print("Content:\\n" + content)

# Read as a list of lines
with open(log_path, "r", encoding="utf-8") as f:
    lines = f.readlines()
assert len(lines) == 3
print(f"Line count: {len(lines)}")

# Append — mode "a" adds to the end without overwriting
with open(log_path, "a", encoding="utf-8") as f:
    f.write("TC-004 PASS\\n")

with open(log_path, "r", encoding="utf-8") as f:
    assert f.read().count("TC-") == 4
print("Pattern 1 ok — text file read / write / append")

log_path.unlink(missing_ok=True)
`} />

**Pattern 2 — `json.loads` and `json.dumps`: string-based JSON**

<En>`json.loads()` converts a JSON string into a Python dict — this is what you use on an API response body. `json.dumps()` converts a dict back to a JSON string — what you send as a request body. The `s` suffix stands for *string*.</En>
<Vi>`json.loads()` chuyển chuỗi JSON thành dict Python — đây là thứ bạn dùng trên phần thân API response. `json.dumps()` chuyển dict trở lại chuỗi JSON — những gì bạn gửi làm phần thân request. Hậu tố `s` là viết tắt của *string*.</Vi>

<CodePlayground code={`
import json

# loads — simulate receiving an API response
response_body = '{"status": "created", "id": 42, "email": "charlie@example.com"}'
parsed = json.loads(response_body)

assert parsed["status"] == "created"
assert isinstance(parsed["id"], int)
print(f"Parsed: {parsed}")

# dumps — build a request body to send
payload = {"email": "bob@example.com", "role": "viewer", "active": True}

compact = json.dumps(payload)              # single line
pretty  = json.dumps(payload, indent=2)   # human-readable

print(f"Compact: {compact}")
print(f"Pretty:\\n{pretty}")

assert '"email"' in compact
assert "bob@example.com" in pretty
print("Pattern 2 ok — json.loads / json.dumps")
`} />

**Pattern 3 — `json.load` and `json.dump`: file-based JSON**

<En>`json.load(f)` reads directly from an open file object. `json.dump(data, f)` writes directly to one. These are the functions you use when loading fixture files or saving test reports — no manual string conversion needed.</En>
<Vi>`json.load(f)` đọc trực tiếp từ đối tượng file đã mở. `json.dump(data, f)` ghi trực tiếp vào đó. Đây là các hàm bạn dùng khi tải file fixture hoặc lưu báo cáo test — không cần chuyển đổi chuỗi thủ công.</Vi>

<CodePlayground code={`
import json
from pathlib import Path

# Write a fixture file
fixture_path = Path("tmp_users.json")
test_users = [
    {"id": 1, "email": "alice@example.com", "role": "admin"},
    {"id": 2, "email": "bob@example.com",   "role": "viewer"},
]
with open(fixture_path, "w", encoding="utf-8") as f:
    json.dump(test_users, f, indent=2)
print(f"Wrote: {fixture_path}")

# Read it back
with open(fixture_path, "r", encoding="utf-8") as f:
    loaded = json.load(f)
assert len(loaded) == 2
assert loaded[0]["email"] == "alice@example.com"
print(f"Loaded {len(loaded)} users")

# Write a test-results report
results_path = Path("tmp_results.json")
report = {"total": 3, "passed": 2, "failed": 1,
          "failures": [{"test": "TC-003", "error": "Expected 200, got 404"}]}
with open(results_path, "w", encoding="utf-8") as f:
    json.dump(report, f, indent=2)
with open(results_path, "r", encoding="utf-8") as f:
    saved = json.load(f)
assert saved["passed"] == 2
print(f"Report: {saved['passed']}/{saved['total']} passed")
print("Pattern 3 ok — json.load / json.dump")

fixture_path.unlink(missing_ok=True)
results_path.unlink(missing_ok=True)
`} />

**Pattern 4 — `pathlib.Path`: modern path handling**

<En>`pathlib.Path` replaces `os.path` string manipulation with an object-oriented API. Use `/` to join segments, `.read_text()` to read in one call, and `.unlink()` to delete. It is the preferred style in modern Python test codebases.</En>
<Vi>`pathlib.Path` thay thế thao tác chuỗi `os.path` bằng API hướng đối tượng. Dùng `/` để nối đoạn, `.read_text()` để đọc trong một lần gọi và `.unlink()` để xoá. Đây là phong cách được ưa thích trong các codebase test Python hiện đại.</Vi>

<CodePlayground code={`
import json
from pathlib import Path

# Build paths with / operator — cross-platform
base     = Path("tests")
fixtures = base / "fixtures"
report   = base / "reports" / "run_001.json"

print(f"Fixtures dir: {fixtures}")
print(f"Report path:  {report}")
print(f"Suffix:       {report.suffix}")   # .json
print(f"Stem:         {report.stem}")     # run_001
print(f"Parent:       {report.parent}")   # tests/reports

# write_text / read_text — no explicit open() needed for simple cases
tmp = Path("tmp_config.json")
config = {"env": "staging", "timeout": 30}
tmp.write_text(json.dumps(config, indent=2), encoding="utf-8")

loaded = json.loads(tmp.read_text(encoding="utf-8"))
assert loaded["env"] == "staging"
assert loaded["timeout"] == 30
print(f"Config loaded: {loaded}")

# exists() and unlink()
assert tmp.exists()
tmp.unlink()
assert not tmp.exists()
print("Pattern 4 ok — pathlib.Path")
`} />
