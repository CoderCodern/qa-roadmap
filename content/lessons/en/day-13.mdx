## Intro

<En>
Loops let you automate repetitive actions — running the same check against many inputs, iterating over API response items, or processing rows in a test data file. In QA automation, `for` loops are used constantly; `while` loops appear less often but are useful for polling and retry logic.
</En>
<Vi>
Vòng lặp cho phép bạn tự động hoá các hành động lặp đi lặp lại — chạy cùng một kiểm tra với nhiều đầu vào, lặp qua các mục trong API response, hoặc xử lý các hàng trong file dữ liệu test. Trong tự động hoá QA, vòng lặp `for` được dùng liên tục; vòng lặp `while` ít xuất hiện hơn nhưng hữu ích cho logic polling và retry.
</Vi>

## Concept

<En>
**`for` loop — iterate over any sequence:**
```python
for item in collection:
    # process item
```

**Key built-ins for loops:**
- `range(n)` — generates 0, 1, …, n-1
- `range(start, stop, step)` — full control
- `enumerate(seq)` — gives (index, value) pairs
- `zip(a, b)` — pairs items from two sequences
- `list comprehension` — `[expr for item in seq if cond]`

**`while` loop — repeat while condition is true:**
```python
while condition:
    # do work
    # update condition or break
```

**Loop control:**
- `break` — exit the loop immediately
- `continue` — skip to the next iteration
- `else` on a loop — runs when the loop completes without `break` (rare but useful for search patterns)

**Common QA patterns:**
- Run a test case for each item in a list of test inputs (parametrisation precursor)
- Retry a flaky operation up to N times with a `while` loop
- Collect failures across all inputs instead of stopping at the first
</En>
<Vi>
**Vòng lặp `for` — lặp qua bất kỳ chuỗi nào:**
```python
for item in collection:
    # xử lý item
```

**Các built-in quan trọng cho vòng lặp:**
- `range(n)` — tạo ra 0, 1, …, n-1
- `enumerate(seq)` — cho các cặp (chỉ số, giá trị)
- `zip(a, b)` — ghép các phần tử từ hai chuỗi
- `list comprehension` — `[expr for item in seq if cond]`

**Vòng lặp `while` — lặp khi điều kiện đúng:**
```python
while condition:
    # thực hiện công việc
    # cập nhật điều kiện hoặc break
```

**Điều khiển vòng lặp:**
- `break` — thoát vòng lặp ngay lập tức
- `continue` — bỏ qua và chuyển sang lần lặp tiếp theo

**Các mẫu QA phổ biến:**
- Chạy test case cho mỗi phần tử trong danh sách đầu vào test
- Thử lại một thao tác không ổn định tối đa N lần với vòng lặp `while`
- Thu thập các lỗi qua tất cả đầu vào thay vì dừng ở lỗi đầu tiên
</Vi>

## Code / Demo

**Pattern 1 — `for` loop: run a check across multiple test inputs**

<En>Collect all failures into a list before asserting. This way you see every broken case at once, not just the first one — a key habit in test automation.</En>
<Vi>Thu thập tất cả lỗi vào một list trước khi assert. Như vậy bạn thấy mọi trường hợp bị hỏng cùng lúc, không chỉ lỗi đầu tiên — thói quen quan trọng trong tự động hoá test.</Vi>

<CodePlayground code={`
test_passwords = [
    ("ValidPass1", True),
    ("hi",         False),     # too short
    ("a" * 21,     False),     # too long
    ("",           False),     # empty
]

def is_valid_password(p):
    return 6 <= len(p) <= 20

failures = []
for password, expected in test_passwords:
    actual = is_valid_password(password)
    if actual != expected:
        failures.append(f"FAIL: {password!r} expected={expected} got={actual}")

if failures:
    for msg in failures:
        print(msg)
else:
    print(f"All {len(test_passwords)} password tests passed!")
print("Pattern 1 ok — for loop across test inputs")
`} />

**Pattern 2 — `enumerate` and `zip`: index-aware iteration**

<En>`enumerate` gives you the index alongside each value — useful for numbered test case IDs. `zip` pairs two sequences together so you can iterate both at once.</En>
<Vi>`enumerate` cho bạn chỉ số kèm theo mỗi giá trị — hữu ích cho ID test case có đánh số. `zip` ghép hai chuỗi lại để bạn có thể lặp cả hai cùng lúc.</Vi>

<CodePlayground code={`
# enumerate — numbered test case IDs
status_codes = [200, 201, 204, 400, 404, 500]
for i, code in enumerate(status_codes, start=1):
    is_success = 200 <= code < 300
    label = "success" if is_success else "not success"
    print(f"TC-{i:03d}: status {code} → {label}")

print()

# zip — pair expected vs actual results
expected = [200, 201, 204]
actual   = [200, 201, 204]
for exp, act in zip(expected, actual):
    assert exp == act, f"Expected {exp}, got {act}"
print("All expected == actual (zip check passed)")
print("Pattern 2 ok — enumerate and zip")
`} />

**Pattern 3 — `while` loop: retry / polling logic**

<En>Use `while` when the number of iterations is unknown and depends on an external condition. Always include a `max_retries` guard so the loop cannot run forever.</En>
<Vi>Dùng `while` khi số vòng lặp không xác định và phụ thuộc vào điều kiện bên ngoài. Luôn thêm giới hạn `max_retries` để vòng lặp không chạy mãi mãi.</Vi>

<CodePlayground code={`
def check_service_ready(attempt):
    return attempt >= 3   # simulates: service becomes ready on attempt 3

max_retries = 5
attempt     = 0
ready       = False

while attempt < max_retries and not ready:
    attempt += 1
    ready = check_service_ready(attempt)
    print(f"Attempt {attempt}: {'ready!' if ready else 'not ready yet'}")

assert ready, f"Service not ready after {max_retries} attempts"
print(f"Service ready after {attempt} attempt(s)")
print("Pattern 3 ok — while retry loop")
`} />

**Pattern 4 — List comprehension: filter and transform in one line**

<En>A list comprehension replaces a for-loop + append pattern with a single readable expression. Add an `if` clause to filter, and an expression before `for` to transform.</En>
<Vi>List comprehension thay thế mẫu for-loop + append bằng một biểu thức có thể đọc được. Thêm mệnh đề `if` để lọc và biểu thức trước `for` để biến đổi.</Vi>

<CodePlayground code={`
all_codes = [200, 201, 301, 400, 404, 500, 503]

# Filter only
error_codes = [c for c in all_codes if c >= 400]

# Filter + transform
error_labels = [f"ERR-{c}" for c in all_codes if c >= 400]

# Transform only
doubled = [c * 2 for c in [1, 2, 3]]

assert error_codes  == [400, 404, 500, 503]
assert error_labels == ["ERR-400", "ERR-404", "ERR-500", "ERR-503"]
assert doubled      == [2, 4, 6]

print(f"Error codes:  {error_codes}")
print(f"Error labels: {error_labels}")
print(f"Doubled:      {doubled}")
print("Pattern 4 ok — list comprehension")
`} />
