## Intro

<En>
Every Python program works with data. Variables are named containers that hold data, and every piece of data has a type. Understanding Python's built-in types and how to inspect them is the foundation for writing any kind of test logic.
</En>
<Vi>
Mọi chương trình Python đều làm việc với dữ liệu. Biến là các container có tên chứa dữ liệu, và mọi dữ liệu đều có một kiểu. Hiểu các kiểu dữ liệu tích hợp của Python và cách kiểm tra chúng là nền tảng để viết bất kỳ loại logic test nào.
</Vi>

## Concept

<En>
**Core data types you'll use constantly in testing:**

| Type | Example | Common use in tests |
|------|---------|---------------------|
| `int` | `42` | status codes, counts |
| `float` | `3.14` | prices, percentages |
| `str` | `"hello"` | usernames, messages, URLs |
| `bool` | `True / False` | assertion results, feature flags |
| `None` | `None` | absent values, empty responses |

**Key rules:**
- Python is dynamically typed — you don't declare the type; Python infers it.
- Use `type(x)` to check the type of any variable.
- Use `isinstance(x, SomeType)` in tests — it handles inheritance correctly.
- `None` is not the same as `0`, `False`, or `""`. Be explicit when checking for `None`.

**Type coercion:** Python won't silently convert between types. `"5" + 5` raises a `TypeError`. Convert explicitly: `int("5") + 5 == 10`.
</En>
<Vi>
**Các kiểu dữ liệu cốt lõi bạn sẽ dùng liên tục trong kiểm thử:**

| Kiểu | Ví dụ | Dùng phổ biến trong test |
|------|---------|---------------------|
| `int` | `42` | mã trạng thái, số đếm |
| `float` | `3.14` | giá cả, phần trăm |
| `str` | `"hello"` | tên người dùng, thông báo, URL |
| `bool` | `True / False` | kết quả assertion, feature flags |
| `None` | `None` | giá trị vắng mặt, response rỗng |

**Các quy tắc quan trọng:**
- Python là ngôn ngữ kiểu động — bạn không khai báo kiểu; Python suy luận nó.
- Dùng `type(x)` để kiểm tra kiểu của bất kỳ biến nào.
- Dùng `isinstance(x, SomeType)` trong test — nó xử lý kế thừa đúng cách.
- `None` không giống `0`, `False`, hay `""`. Hãy rõ ràng khi kiểm tra `None`.

**Chuyển đổi kiểu:** Python sẽ không tự động chuyển đổi giữa các kiểu. `"5" + 5` sẽ gây ra `TypeError`. Chuyển đổi tường minh: `int("5") + 5 == 10`.
</Vi>

## Code / Demo

```python
# Variables — no type declarations needed
status_code = 200
username = "alice"
is_logged_in = True
response_body = None
price = 29.99

# Check types
print(type(status_code))    # <class 'int'>
print(type(username))       # <class 'str'>
print(type(is_logged_in))   # <class 'bool'>
print(type(response_body))  # <class 'NoneType'>

# isinstance is safer in tests than type() ==
assert isinstance(status_code, int)
assert isinstance(username, str)

# Truthiness — common in test conditions
assert status_code          # 200 is truthy
assert not response_body    # None is falsy
assert is_logged_in         # True is truthy

# Explicit None check (preferred over 'if x is not None')
if response_body is None:
    print("No response body — expected for 204 responses")

# Type conversion
raw = "404"
code = int(raw)
assert code == 404
print(f"Converted '{raw}' to integer {code}")
```
