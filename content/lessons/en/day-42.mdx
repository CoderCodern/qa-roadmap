## Intro

<En>
Field-by-field assertions work for simple responses, but what about a response with 30 fields and 5 nested objects? JSON Schema validation lets you define the expected structure of a response once, then validate any response against it in a single assertion. It's the difference between checking every field manually and declaring a contract.
</En>
<Vi>
Các assertion từng trường hoạt động cho các response đơn giản, nhưng còn response với 30 trường và 5 object lồng nhau thì sao? Xác thực JSON Schema cho phép bạn định nghĩa cấu trúc mong đợi của response một lần, sau đó xác thực bất kỳ response nào với nó trong một assertion duy nhất. Đó là sự khác biệt giữa kiểm tra từng trường thủ công và khai báo một contract.
</Vi>

## Concept

<En>
**JSON Schema basics:**
A JSON Schema is a JSON object that describes what another JSON object should look like:

```json
{
  "type": "object",
  "required": ["id", "email", "role"],
  "properties": {
    "id":    { "type": "integer", "minimum": 1 },
    "email": { "type": "string", "format": "email" },
    "role":  { "type": "string", "enum": ["admin", "editor", "viewer"] },
    "name":  { "type": "string" }
  },
  "additionalProperties": false
}
```

**Key schema keywords:**

| Keyword | Description |
|---------|-------------|
| `type` | `"string"`, `"integer"`, `"number"`, `"boolean"`, `"null"`, `"array"`, `"object"` |
| `required` | List of field names that must be present |
| `properties` | Schema for each named field |
| `items` | Schema for array elements |
| `enum` | List of allowed values |
| `minimum` / `maximum` | Numeric range constraints |
| `minLength` / `maxLength` | String length range constraints |
| `additionalProperties` | Whether unlisted fields are allowed (`false` = strict) |

**Python library:**
```bash
pip install jsonschema
```

```python
from jsonschema import validate, ValidationError

validate(instance=data, schema=schema)  # raises ValidationError if invalid
```

The `validate()` call raises `ValidationError` with a descriptive message telling you exactly which field failed and why. If validation passes, it returns `None` silently.

**Nested schemas:**
You can define schemas for nested objects and arrays. Use `"items"` for array element schemas:

```json
{
  "type": "array",
  "items": {
    "type": "object",
    "required": ["id", "title"],
    "properties": {
      "id":    { "type": "integer" },
      "title": { "type": "string", "minLength": 1 }
    }
  },
  "minItems": 1
}
```

**Where to store schemas:**
- Inline dicts in test files — suitable for simple schemas used in one place
- Separate `.json` files in a `schemas/` directory — for large schemas or schemas reused across multiple test files

```python
import json
from pathlib import Path

schema = json.loads(Path("schemas/post.json").read_text())
validate(instance=response.json(), schema=schema)
```
</En>
<Vi>
**JSON Schema cơ bản:**
JSON Schema là một JSON object mô tả một JSON object khác trông như thế nào:

```json
{
  "type": "object",
  "required": ["id", "email", "role"],
  "properties": {
    "id":    { "type": "integer", "minimum": 1 },
    "email": { "type": "string", "format": "email" },
    "role":  { "type": "string", "enum": ["admin", "editor", "viewer"] },
    "name":  { "type": "string" }
  },
  "additionalProperties": false
}
```

**Các từ khóa schema quan trọng:**

| Từ khóa | Mô tả |
|---------|-------------|
| `type` | `"string"`, `"integer"`, `"number"`, `"boolean"`, `"null"`, `"array"`, `"object"` |
| `required` | Danh sách tên trường phải có mặt |
| `properties` | Schema cho từng trường được đặt tên |
| `items` | Schema cho các phần tử trong mảng |
| `enum` | Danh sách các giá trị được phép |
| `minimum` / `maximum` | Ràng buộc phạm vi số |
| `minLength` / `maxLength` | Ràng buộc độ dài chuỗi |
| `additionalProperties` | Có cho phép trường không được liệt kê không (`false` = nghiêm ngặt) |

**Thư viện Python:**
```bash
pip install jsonschema
```

```python
from jsonschema import validate, ValidationError

validate(instance=data, schema=schema)  # raise ValidationError nếu không hợp lệ
```

Hàm `validate()` raise `ValidationError` với thông báo mô tả chính xác trường nào thất bại và tại sao. Nếu xác thực thành công, nó trả về `None` lặng lẽ.

**Schema lồng nhau:**
Bạn có thể định nghĩa schema cho các object và mảng lồng nhau. Dùng `"items"` cho schema của phần tử mảng:

```json
{
  "type": "array",
  "items": {
    "type": "object",
    "required": ["id", "title"],
    "properties": {
      "id":    { "type": "integer" },
      "title": { "type": "string", "minLength": 1 }
    }
  },
  "minItems": 1
}
```

**Nơi lưu trữ schema:**
- Dict nội tuyến trong file test — phù hợp cho schema đơn giản dùng ở một chỗ
- File `.json` riêng trong thư mục `schemas/` — dành cho schema lớn hoặc dùng ở nhiều file test

```python
import json
from pathlib import Path

schema = json.loads(Path("schemas/post.json").read_text())
validate(instance=response.json(), schema=schema)
```

## Code / Demo

<En>

**Part 1 — Define schemas and validate a single object**

</En>
<Vi>

**Phần 1 — Định nghĩa schema và xác thực một object**

</Vi>

```python
import requests
from jsonschema import validate, ValidationError

# --- Schema definitions ---
POST_SCHEMA = {
    "type": "object",
    "required": ["id", "userId", "title", "body"],
    "properties": {
        "id":     {"type": "integer", "minimum": 1},
        "userId": {"type": "integer", "minimum": 1},
        "title":  {"type": "string",  "minLength": 1},
        "body":   {"type": "string",  "minLength": 1},
    },
    "additionalProperties": False,
}

USER_SCHEMA = {
    "type": "object",
    "required": ["id", "name", "username", "email"],
    "properties": {
        "id":       {"type": "integer", "minimum": 1},
        "name":     {"type": "string",  "minLength": 1},
        "username": {"type": "string",  "minLength": 1},
        "email":    {"type": "string"},
        "phone":    {"type": "string"},
        "website":  {"type": "string"},
        "address":  {"type": "object"},
        "company":  {"type": "object"},
    },
}

BASE_URL = "https://jsonplaceholder.typicode.com"

def test_single_post_schema():
    response = requests.get(f"{BASE_URL}/posts/1")
    assert response.status_code == 200
    validate(instance=response.json(), schema=POST_SCHEMA)
    print("POST schema valid!")

def test_user_schema():
    response = requests.get(f"{BASE_URL}/users/1")
    assert response.status_code == 200
    validate(instance=response.json(), schema=USER_SCHEMA)
    print("USER schema valid!")

test_single_post_schema()
test_user_schema()
```

<En>

**Part 2 — Validate a list response and catch schema violations**

</En>
<Vi>

**Phần 2 — Xác thực response dạng danh sách và bắt lỗi vi phạm schema**

</Vi>

```python
POSTS_LIST_SCHEMA = {
    "type": "array",
    "items": POST_SCHEMA,
    "minItems": 1,
}

def test_posts_list_schema():
    response = requests.get(f"{BASE_URL}/posts", params={"_limit": 5})
    assert response.status_code == 200
    validate(instance=response.json(), schema=POSTS_LIST_SCHEMA)
    print("Posts list schema valid!")

def test_schema_catches_invalid_data():
    # Simulate bad API data: id is a string instead of integer
    bad_data = {"id": "not-an-integer", "userId": 1, "title": "x", "body": "y"}
    try:
        validate(instance=bad_data, schema=POST_SCHEMA)
        assert False, "Validation should have failed"
    except ValidationError as e:
        print(f"Correctly caught: {e.message}")
        # e.path shows which field failed: deque(['id'])
        print(f"Failed at field: {list(e.path)}")

test_posts_list_schema()
test_schema_catches_invalid_data()
print("All schema validation tests passed!")
```

<En>

**Part 3 — Load schemas from external JSON files**

</En>
<Vi>

**Phần 3 — Tải schema từ file JSON bên ngoài**

</Vi>

```python
import json
from pathlib import Path

# schemas/post.json would contain the POST_SCHEMA dict above
# This pattern is useful when schemas are shared across multiple test files

def load_schema(name: str) -> dict:
    schema_path = Path("schemas") / f"{name}.json"
    return json.loads(schema_path.read_text())

def test_with_external_schema():
    # schema = load_schema("post")  # uncomment when schemas/ directory exists
    schema = POST_SCHEMA  # using inline for demo
    response = requests.get(f"{BASE_URL}/posts/1")
    assert response.status_code == 200
    validate(instance=response.json(), schema=schema)
    print("External schema validation passed!")

test_with_external_schema()
```
