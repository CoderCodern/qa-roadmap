## Intro

<En>
Even the best-written tests break sometimes — the app changes, a selector stops matching, a timing issue emerges. Knowing how to debug efficiently is what separates an automation engineer who spends hours guessing from one who pinpoints the problem in minutes.

Playwright has world-class debugging tools: the **Playwright Inspector** (step through your test like a debugger), **PWDEBUG** mode, **pause()**, and the **codegen** tool that records your clicks and generates code. Combined with headed mode and slow-mo, you have everything needed to understand exactly what's happening.
</En>
<Vi>
Ngay cả test được viết tốt nhất đôi khi cũng bị hỏng — ứng dụng thay đổi, selector không còn khớp, vấn đề timing nổi lên. Biết cách debug hiệu quả là điều phân biệt kỹ sư automation mất hàng giờ đoán mò với người xác định vấn đề trong vài phút.

Playwright có công cụ debug đẳng cấp thế giới: **Playwright Inspector** (bước qua test như debugger), chế độ **PWDEBUG**, **pause()** và công cụ **codegen** ghi lại click của bạn và tạo code.
</Vi>

## Concept

<En>
**The debugging toolkit — choose by situation:**

| Tool | How to use | Best for |
|------|-----------|---------|
| `headless=False` | `browser.launch(headless=False)` | Watching what the browser does |
| `slow_mo=N` | `browser.launch(slow_mo=500)` | Seeing each action with a delay |
| `page.pause()` | Add in script/test | Stop at a specific point, then use Inspector |
| PWDEBUG mode | `PWDEBUG=1 pytest ...` | Full Inspector for your pytest run |
| `page.screenshot()` | Add in test | Capture the page at failure |
| Playwright Inspector | Opens with PWDEBUG or pause() | Step through actions, try locators live |
| codegen | `playwright codegen <url>` | Record clicks and generate Python code |
| Trace Viewer | `playwright show-trace trace.zip` | Post-mortem analysis of recorded tests |

**Headed mode and slow_mo:**
```bash
# From CLI when running pytest
pytest tests/ --headed                    # show browser window
pytest tests/ --headed --slowmo 500       # show window + 500ms delay

# From Python
browser = p.chromium.launch(headless=False, slow_mo=500)
```

**pause() — the most powerful in-test debugger:**
```python
# Add pause() anywhere in your script or test
page.pause()  # execution stops here; Playwright Inspector opens
# You can inspect the DOM, try locators, step forward
# Press "Resume" in Inspector to continue, or close to abort
```

**PWDEBUG=1 — debug entire pytest runs:**
```bash
# macOS/Linux
PWDEBUG=1 pytest tests/test_login.py -v

# Windows (Command Prompt)
set PWDEBUG=1 && pytest tests/test_login.py -v

# Windows (PowerShell)
$env:PWDEBUG=1; pytest tests/test_login.py -v
```

When PWDEBUG=1 is set:
- Browser opens in headed mode
- Playwright Inspector opens alongside
- Tests run step-by-step — press "Step" to advance, "Resume" to run to completion

**Playwright Inspector features:**
- Pick mode: click any element to see its suggested locator
- Test locators live in the selector bar
- See all actions in the action log
- Step through test one action at a time

**codegen — record and replay:**
```bash
# Opens a browser + Inspector; click around, code is generated automatically
playwright codegen https://practicesoftwaretesting.com

# Save generated code directly to a file
playwright codegen https://practicesoftwaretesting.com --output my_test.py

# Use a specific browser
playwright codegen --browser firefox https://example.com
```

**Common debugging patterns:**
```python
# Pattern 1: screenshot at failure point
def test_something(page):
    try:
        page.goto("https://example.com")
        expect(page.locator(".result")).to_be_visible()
    except Exception:
        page.screenshot(path="debug_failure.png", full_page=True)
        raise  # re-raise so the test still fails

# Pattern 2: print locator info before acting
locator = page.get_by_role("button", name="Submit")
print(f"Button count: {locator.count()}")
print(f"Button visible: {locator.is_visible()}")
locator.click()

# Pattern 3: evaluate JavaScript to inspect the DOM
value = page.evaluate("document.querySelector('#email').value")
print(f"Email input value: {value}")

# Pattern 4: check what URL we're on
print(f"Current URL: {page.url}")
print(f"Page title: {page.title()}")
```
</En>

<En>

**Part 1 — Headed mode with slow_mo to watch automation live**

</En>
<Vi>

**Phần 1 — Chế độ headed với slow_mo để xem automation trực tiếp**

</Vi>

```python
# demo_headed_slowmo.py
# Run with: python demo_headed_slowmo.py
# Watch a real browser window as it navigates and interacts
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    # headless=False → visible window
    # slow_mo=800   → 800ms pause between each action
    browser = p.chromium.launch(headless=False, slow_mo=800)
    page = browser.new_page()

    print("Step 1: Opening homepage...")
    page.goto("https://practicesoftwaretesting.com")

    print("Step 2: Searching for 'Hammer'...")
    search = page.get_by_role("textbox", name="Search")
    search.fill("Hammer")    # slow_mo: you'll see it typed slowly
    search.press("Enter")

    page.wait_for_load_state("networkidle")

    print("Step 3: Reading results...")
    count = page.locator(".card").count()
    print(f"Found {count} product(s)")

    print("Step 4: Clicking first result...")
    page.locator(".card").first.click()

    page.wait_for_load_state("networkidle")
    print(f"Product page URL: {page.url}")
    print(f"Product title: {page.title()}")

    browser.close()
    print("Done!")
```

**Part 3 — Debugging patterns in pytest tests**

**Phần 3 — Các kỹ thuật debug trong pytest test**

</Vi>

```python
# tests/test_debug_patterns.py
# Run with: pytest tests/test_debug_patterns.py -v -s
# (-s flag shows print() output in pytest)
from playwright.sync_api import Page, expect
import pytest

BASE = "https://practicesoftwaretesting.com"

def test_with_debug_info(page: Page):
    """Shows how to add debugging info that helps when a test fails."""
    page.goto(BASE)
    page.wait_for_load_state("networkidle")

    # Debug: print page state
    print(f"\nURL   : {page.url}")
    print(f"Title : {page.title()}")

    # Debug: count elements before asserting
    cards = page.locator(".card")
    print(f"Cards : {cards.count()}")

    # Debug: check a locator before using it
    search = page.get_by_role("textbox", name="Search")
    print(f"Search visible : {search.is_visible()}")
    print(f"Search enabled : {search.is_enabled()}")

    # Now make the assertion
    expect(search).to_be_visible()
    assert cards.count() > 0, "Expected products on homepage"

def test_screenshot_on_step(page: Page, tmp_path):
    """Take screenshots at key steps for documentation/debugging."""
    page.goto(BASE)
    page.screenshot(path=str(tmp_path / "01_homepage.png"))

    page.get_by_role("textbox", name="Search").fill("Pliers")
    page.screenshot(path=str(tmp_path / "02_search_filled.png"))

    page.get_by_role("textbox", name="Search").press("Enter")
    page.wait_for_load_state("networkidle")
    page.screenshot(path=str(tmp_path / "03_results.png"))

    print(f"\nScreenshots saved to: {tmp_path}")
    assert page.locator(".card").count() > 0
```
