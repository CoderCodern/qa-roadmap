## Intro

<En>
Test logic is full of branching decisions: if the status is 200 do this, otherwise do that. Python's `if`, `elif`, and `else` statements let you express those decisions clearly. Learning to write clean conditionals — and to prefer early returns over deep nesting — makes your test code much easier to read and debug.
</En>
<Vi>
Logic test đầy các quyết định phân nhánh: nếu trạng thái là 200 thì làm điều này, ngược lại thì làm điều khác. Các câu lệnh `if`, `elif` và `else` của Python cho phép bạn diễn đạt những quyết định đó một cách rõ ràng. Học cách viết điều kiện gọn gàng — và ưu tiên return sớm hơn lồng sâu — làm cho code test của bạn dễ đọc và debug hơn nhiều.
</Vi>

## Concept

<En>
**Basic structure:**
```python
if condition:
    # runs when condition is True
elif other_condition:
    # runs when other_condition is True (and first was False)
else:
    # runs when all conditions above are False
```

**Key rules:**
- Indentation (4 spaces) defines the block — Python has no `{}` braces.
- Any value can be used as a condition — Python evaluates its truthiness.
- `elif` is optional and can be chained. `else` is optional too.

**Prefer early returns over nesting:** Deep nesting is a code smell. Instead of nesting three `if` blocks, return early on the failure cases.

**Ternary expression** — for simple single-line conditionals:
```python
label = "pass" if score >= 60 else "fail"
```

**`match` statement (Python 3.10+):** Useful for checking a value against multiple exact values (similar to `switch`). Use for status codes, error codes, roles.
</En>
<Vi>
**Cấu trúc cơ bản:**
```python
if condition:
    # chạy khi condition là True
elif other_condition:
    # chạy khi other_condition là True (và điều đầu tiên là False)
else:
    # chạy khi tất cả các điều kiện trên đều False
```

**Các quy tắc quan trọng:**
- Thụt lề (4 dấu cách) xác định khối — Python không có dấu ngoặc nhọn `{}`.
- Bất kỳ giá trị nào cũng có thể dùng làm điều kiện — Python đánh giá tính đúng/sai của nó.
- `elif` là tùy chọn và có thể được xâu chuỗi. `else` cũng là tùy chọn.

**Ưu tiên return sớm hơn lồng sâu:** Lồng sâu là code smell. Thay vì lồng ba khối `if`, hãy return sớm ở các trường hợp thất bại.

**Biểu thức ba ngôi** — cho điều kiện đơn giản một dòng:
```python
label = "pass" if score >= 60 else "fail"
```
</Vi>

## Code / Demo

**Pattern 1 — `if / elif / else`: classify a value into categories**

<En>Chain `elif` clauses to map a value into one of several categories. Each branch is checked in order — the first one that is `True` wins, and the rest are skipped.</En>
<Vi>Nối các mệnh đề `elif` để ánh xạ một giá trị vào một trong nhiều danh mục. Mỗi nhánh được kiểm tra theo thứ tự — cái đầu tiên là `True` sẽ thắng, và phần còn lại bị bỏ qua.</Vi>

<CodePlayground code={`
def classify_status_code(code):
    if code < 100 or code > 599:
        return "invalid"
    elif code < 200:
        return "informational"
    elif code < 300:
        return "success"
    elif code < 400:
        return "redirect"
    elif code < 500:
        return "client_error"
    else:
        return "server_error"

assert classify_status_code(200) == "success"
assert classify_status_code(404) == "client_error"
assert classify_status_code(500) == "server_error"
assert classify_status_code(301) == "redirect"
assert classify_status_code(99)  == "invalid"

for code in [200, 301, 404, 500]:
    print(f"  {code} → {classify_status_code(code)}")
print("Pattern 1 ok — if / elif / else")
`} />

**Pattern 2 — Guard clauses: early returns instead of nesting**

<En>Instead of nesting `if` inside `if`, return early on each invalid case. The main success logic stays flat at the lowest indentation level, making it easy to follow.</En>
<Vi>Thay vì lồng `if` bên trong `if`, hãy return sớm với mỗi trường hợp không hợp lệ. Logic thành công chính vẫn phẳng ở mức thụt lề thấp nhất, giúp dễ theo dõi.</Vi>

<CodePlayground code={`
def validate_login_response(response):
    if response is None:
        return "No response received"
    if "token" not in response:
        return "Missing token in response"
    if not isinstance(response["token"], str):
        return "Token must be a string"
    if len(response["token"]) < 10:
        return "Token is too short"
    return "OK"   # happy path — only reached if all guards pass

good        = {"token": "eyJhbGciOiJIUzI1NiJ9.abc123"}
no_token    = {"user": "alice"}
short_token = {"token": "abc"}

print(validate_login_response(good))         # OK
print(validate_login_response(no_token))     # Missing token in response
print(validate_login_response(None))         # No response received
print(validate_login_response(short_token))  # Token is too short

assert validate_login_response(good) == "OK"
assert validate_login_response(None) != "OK"
print("Pattern 2 ok — guard clauses")
`} />

**Pattern 3 — Ternary expressions: single-line conditionals**

<En>Use the ternary form `value_if_true if condition else value_if_false` for simple label or flag assignments. Avoid nesting ternaries — if the logic is complex, use a regular `if/else` block instead.</En>
<Vi>Dùng dạng ternary `giá_trị_nếu_true if điều_kiện else giá_trị_nếu_false` cho việc gán nhãn hoặc cờ đơn giản. Tránh lồng ternary — nếu logic phức tạp, hãy dùng khối `if/else` thông thường.</Vi>

<CodePlayground code={`
score    = 75
latency  = 320
is_admin = False

# Ternary — clean for simple two-way decisions
result   = "pass"   if score   >= 60  else "fail"
perf     = "fast"   if latency <= 200 else "slow"
role     = "admin"  if is_admin        else "viewer"

print(f"Score {score}:    {result}")
print(f"Latency {latency}ms: {perf}")
print(f"Role:           {role}")

assert result == "pass"
assert perf   == "slow"
assert role   == "viewer"
print("Pattern 3 ok — ternary expressions")
`} />
