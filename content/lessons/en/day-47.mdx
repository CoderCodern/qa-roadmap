**Design decisions and why:**

- **`ApiClient` wraps `requests.Session`**: base URL is defined in one place. If JSONPlaceholder ever changes its domain, you update one constant instead of every test file.
- **`__init__.py` in `api/` and `tests/`**: makes them Python packages. This allows absolute imports like `from api.client import ApiClient` to work without path manipulation.
- **Schemas stored as JSON files**: reusable across multiple test files, editable without touching test logic, and shareable with the API team as contract documentation.
- **`scope="session"` fixture for `ApiClient`**: the underlying `requests.Session` pools TCP connections — one session for the whole test run means fewer TCP handshakes and faster tests.
- **Separate test files by resource (`test_posts.py`, `test_users.py`)**: each file owns a single resource. It's easy to run just `pytest tests/test_posts.py` when you're working on post-related tests.
- **Negative tests in `test_negative.py`**: clear separation of concern — positive tests verify happy paths, negative tests verify resilience.

**How to import a JSON schema from a file:**
```python
import json
from pathlib import Path

schema = json.loads(Path("schemas/post.json").read_text())
```
`Path.read_text()` reads the file contents as a string; `json.loads()` parses it into a Python dict that `jsonschema.validate()` accepts.

**What `validate(instance=data, schema=schema)` does when validation fails:**
It raises `jsonschema.ValidationError` with a human-readable message describing exactly which field failed and why (e.g., `'title' is a required property`). This makes schema assertion failures much more informative than a bare `assert "title" in data`.

**Các quyết định thiết kế và lý do:**

- **`ApiClient` bọc `requests.Session`**: base URL được định nghĩa ở một chỗ. Nếu JSONPlaceholder thay đổi domain, bạn chỉ cập nhật một hằng số thay vì mọi file test.
- **`__init__.py` trong `api/` và `tests/`**: biến chúng thành Python package. Điều này cho phép import tuyệt đối như `from api.client import ApiClient` hoạt động mà không cần thao tác đường dẫn.
- **Schema lưu dưới dạng JSON file**: có thể tái sử dụng trên nhiều file test, chỉnh sửa mà không cần đụng vào logic test, và chia sẻ với team API như tài liệu contract.
- **Fixture `scope="session"` cho `ApiClient`**: `requests.Session` bên dưới pool các kết nối TCP — một session cho toàn bộ test run có nghĩa là ít TCP handshake hơn và test nhanh hơn.
- **File test riêng biệt theo tài nguyên**: mỗi file sở hữu một tài nguyên. Dễ dàng chạy chỉ `pytest tests/test_posts.py` khi bạn đang làm việc với test liên quan đến post.
- **Test tiêu cực trong `test_negative.py`**: phân tách rõ ràng — test tích cực xác minh happy path, test tiêu cực xác minh khả năng phục hồi.

**Cách import JSON schema từ file:**
```python
import json
from pathlib import Path

schema = json.loads(Path("schemas/post.json").read_text())
```
`Path.read_text()` đọc nội dung file dưới dạng string; `json.loads()` phân tích nó thành Python dict mà `jsonschema.validate()` chấp nhận.

**`validate(instance=data, schema=schema)` làm gì khi xác thực thất bại:**
Nó ném `jsonschema.ValidationError` với thông báo dễ đọc mô tả chính xác trường nào thất bại và tại sao (ví dụ: `'title' is a required property`). Điều này làm cho lỗi xác thực schema thông tin hơn nhiều so với `assert "title" in data` thuần túy.

```python
# api/client.py
import requests
from typing import Any

class ApiClient:
    BASE_URL = "https://jsonplaceholder.typicode.com"

    def __init__(self) -> None:
        self.session = requests.Session()
        self.session.headers.update({"Content-Type": "application/json"})

    def get(self, path: str, **kwargs: Any) -> requests.Response:
        return self.session.get(f"{self.BASE_URL}{path}", **kwargs)

    def post(self, path: str, **kwargs: Any) -> requests.Response:
        return self.session.post(f"{self.BASE_URL}{path}", **kwargs)

    def put(self, path: str, **kwargs: Any) -> requests.Response:
        return self.session.put(f"{self.BASE_URL}{path}", **kwargs)

    def patch(self, path: str, **kwargs: Any) -> requests.Response:
        return self.session.patch(f"{self.BASE_URL}{path}", **kwargs)

    def delete(self, path: str, **kwargs: Any) -> requests.Response:
        return self.session.delete(f"{self.BASE_URL}{path}", **kwargs)
```

```python
# tests/conftest.py
import json
import pytest
from pathlib import Path
from api.client import ApiClient

@pytest.fixture(scope="session")
def api() -> ApiClient:
    # scope="session" means this runs once per test run — not once per test.
    # All tests share the same ApiClient and its underlying requests.Session.
    return ApiClient()

@pytest.fixture(scope="session")
def post_schema() -> dict:
    return json.loads(Path("schemas/post.json").read_text())

@pytest.fixture(scope="session")
def user_schema() -> dict:
    return json.loads(Path("schemas/user.json").read_text())
```

```python
# tests/test_posts.py
import pytest
from jsonschema import validate
from api.client import ApiClient

def test_get_post(api: ApiClient, post_schema: dict):
    response = api.get("/posts/1")
    assert response.status_code == 200
    validate(instance=response.json(), schema=post_schema)

def test_get_all_posts(api: ApiClient):
    response = api.get("/posts")
    assert response.status_code == 200
    posts = response.json()
    assert isinstance(posts, list)
    assert len(posts) == 100

@pytest.mark.parametrize("post_id", [1, 25, 50, 75, 100])
def test_get_post_by_id(api: ApiClient, post_id: int, post_schema: dict):
    response = api.get(f"/posts/{post_id}")
    assert response.status_code == 200
    post = response.json()
    validate(instance=post, schema=post_schema)
    assert post["id"] == post_id

def test_create_post(api: ApiClient):
    payload = {"title": "QA Test Post", "body": "Automated test body", "userId": 1}
    response = api.post("/posts", json=payload)
    assert response.status_code == 201
    created = response.json()
    assert "id" in created
    assert created["title"] == payload["title"]
    assert created["userId"] == payload["userId"]

def test_update_post(api: ApiClient):
    payload = {"id": 1, "title": "Updated Title", "body": "Updated body", "userId": 1}
    response = api.put("/posts/1", json=payload)
    assert response.status_code == 200
    assert response.json()["title"] == "Updated Title"

def test_partial_update_post(api: ApiClient):
    response = api.patch("/posts/1", json={"title": "Patched Title"})
    assert response.status_code == 200
    assert response.json()["title"] == "Patched Title"

def test_delete_post(api: ApiClient):
    response = api.delete("/posts/1")
    assert response.status_code == 200

def test_get_post_comments(api: ApiClient):
    # Tests the nested resource endpoint — different from /comments?postId=1
    response = api.get("/posts/1/comments")
    assert response.status_code == 200
    comments = response.json()
    assert isinstance(comments, list)
    assert len(comments) > 0
    for comment in comments:
        assert comment["postId"] == 1
```
