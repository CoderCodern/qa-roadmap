## Intro

<En>
Lists and tuples are Python's two core sequence types. In testing, you'll use lists constantly — to hold test cases, store API response items, collect failures, and iterate. Tuples appear in fixtures, coordinate pairs, and any time you want an ordered collection that should not change. Knowing which to use, and how to work with them efficiently, is essential for clean test code.
</En>
<Vi>
List và tuple là hai kiểu chuỗi cốt lõi của Python. Trong kiểm thử, bạn sẽ dùng list liên tục — để chứa test case, lưu trữ các mục API response, thu thập lỗi và lặp qua. Tuple xuất hiện trong fixture, cặp tọa độ, và bất cứ khi nào bạn muốn một tập hợp có thứ tự mà không nên thay đổi. Biết cái nào để dùng và cách làm việc với chúng hiệu quả là thiết yếu cho code test gọn sạch.
</Vi>

## Concept

<En>
**List — mutable, ordered:**
```python
items = [1, 2, 3]
items.append(4)      # add to end
items.insert(0, 0)   # insert at index
items.remove(2)      # remove first occurrence of value
items.pop()          # remove and return last item
items.sort()         # sort in place
```

**Tuple — immutable, ordered:**
```python
point = (10, 20)     # parentheses optional
x, y = point         # unpacking
pair = "alice", "admin"  # no parentheses needed
```

**Slicing** works on both:
```python
first_three = items[:3]
last_two = items[-2:]
reversed_list = items[::-1]
```

**Key list methods for QA:**

| Method | Use case |
|--------|---------|
| `len(items)` | Check item count in response |
| `items[0]` | Get first result |
| `items[-1]` | Get last result |
| `x in items` | Membership check |
| `sorted(items)` | Sort without mutation |
| `list(filter(fn, items))` | Filter a list |
| `[x for x in items if cond]` | List comprehension filter |

**When to use which:**
- Use **list** when the collection will grow, shrink, or be mutated.
- Use **tuple** for fixed-size records (test case row), return values, or dict keys.
</En>
<Vi>
**List — có thể thay đổi, có thứ tự:**
```python
items = [1, 2, 3]
items.append(4)      # thêm vào cuối
items.insert(0, 0)   # chèn tại chỉ số
items.remove(2)      # xoá lần xuất hiện đầu tiên
items.pop()          # xoá và trả về item cuối
items.sort()         # sắp xếp tại chỗ
```

**Tuple — không thể thay đổi, có thứ tự:**
```python
point = (10, 20)
x, y = point         # giải nén
```

**Slicing** hoạt động trên cả hai:
```python
first_three = items[:3]
last_two = items[-2:]
```

**Khi nào dùng cái nào:**
- Dùng **list** khi tập hợp sẽ tăng, giảm hoặc bị thay đổi.
- Dùng **tuple** cho bản ghi kích thước cố định (hàng test case), giá trị trả về hoặc key dict.
</Vi>

## Code / Demo

**Pattern 1 — List basics: create, mutate, inspect**

<En>Lists are mutable — you can add, insert, remove, and pop items. These are the operations you'll use when collecting test results, building request payloads, or managing test fixtures.</En>
<Vi>List có thể thay đổi — bạn có thể thêm, chèn, xoá và lấy item. Đây là các thao tác bạn dùng khi thu thập kết quả test, xây dựng payload request hoặc quản lý test fixture.</Vi>

<CodePlayground code={`
items = ["apple", "banana", "cherry"]

items.append("date")          # add to end
items.insert(1, "avocado")    # insert at index 1
popped = items.pop()          # remove and return last item
removed = items.pop(0)        # remove and return item at index 0

assert popped == "date"
assert removed == "apple"
assert items == ["avocado", "banana", "cherry"]

print(f"List: {items}")
print(f"Length: {len(items)}")
print("Pattern 1 ok — list mutation")
`} />

**Pattern 2 — Tuples: immutable records + unpacking**

<En>Tuples hold fixed-size records. Tuple unpacking lets you destructure them cleanly in a `for` loop — perfect for parametrised test cases where each row is `(input, expected)`.</En>
<Vi>Tuple chứa bản ghi kích thước cố định. Giải nén tuple cho phép bạn destructure chúng gọn gàng trong vòng lặp `for` — hoàn hảo cho các test case tham số hoá khi mỗi hàng là `(input, expected)`.</Vi>

<CodePlayground code={`
# Tuple basics — immutable, unpackable
point = (10, 20)
x, y = point
assert x == 10 and y == 20

# List of tuples — parametrised test data
test_cases = [
    ("user@example.com", "ValidPass1", True),
    ("bad-email",        "ValidPass1", False),
    ("",                 "",           False),
]

def simulate_login(email, password):
    return email == "user@example.com" and password == "ValidPass1"

for email, password, expected in test_cases:
    assert simulate_login(email, password) == expected, f"FAIL: {email!r}"

print(f"All {len(test_cases)} test cases passed!")
print("Pattern 2 ok — tuples and unpacking")
`} />

**Pattern 3 — List comprehension + filtering API responses**

<En>List comprehensions replace `filter()` + `lambda` with a single readable expression. In QA you'll use them constantly to extract specific items from API response arrays.</En>
<Vi>List comprehension thay thế `filter()` + `lambda` bằng một biểu thức có thể đọc được duy nhất. Trong QA bạn sẽ dùng chúng liên tục để trích xuất các item cụ thể từ mảng API response.</Vi>

<CodePlayground code={`
response_items = [
    {"id": 1, "status": "active"},
    {"id": 2, "status": "inactive"},
    {"id": 3, "status": "active"},
]

# Filter with list comprehension
active = [item for item in response_items if item["status"] == "active"]
assert len(active) == 2

# Extract a field into a flat list
statuses = [item["status"] for item in response_items]

# Membership check
assert "active" in statuses
assert "deleted" not in statuses

print(f"Active: {len(active)}/{len(response_items)}")
print(f"Statuses: {statuses}")
print("Pattern 3 ok — list comprehension and filtering")
`} />

**Pattern 4 — Slicing and sorting**

<En>Slicing extracts sub-sequences without mutating the original. `sorted()` returns a new sorted list; `.sort()` sorts in place. Prefer `sorted()` when you need the original unchanged.</En>
<Vi>Slicing trích xuất dãy con mà không thay đổi bản gốc. `sorted()` trả về list mới đã sắp xếp; `.sort()` sắp xếp tại chỗ. Ưu tiên `sorted()` khi bạn cần giữ nguyên bản gốc.</Vi>

<CodePlayground code={`
scores = [85, 42, 91, 67, 73, 55]

# Slicing
first_three  = scores[:3]
last_two     = scores[-2:]
every_other  = scores[::2]
reversed_all = scores[::-1]

assert first_three == [85, 42, 91]
assert last_two    == [73, 55]
print(f"First 3:    {first_three}")
print(f"Last 2:     {last_two}")
print(f"Every 2nd:  {every_other}")
print(f"Reversed:   {reversed_all}")

# sorted() → new list, .sort() → mutates in place
top3 = sorted(scores, reverse=True)[:3]
assert scores[0] == 85    # original is unchanged
assert top3 == [91, 85, 73]
print(f"Top 3: {top3}")
print("Pattern 4 ok — slicing and sorting")
`} />
