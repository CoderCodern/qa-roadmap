## Intro

<En>
The capstone project is your chance to demonstrate everything from the past eight weeks in one cohesive, professional framework. Today you kick off the project: you define requirements, choose your target application, scaffold the full directory structure, and write your first passing test. By the end of this session your framework is alive — not just a plan.
</En>

Hôm nay bạn khởi động dự án: xác định yêu cầu, chọn ứng dụng mục tiêu, khởi tạo cấu trúc thư mục đầy đủ và viết test đầu tiên vượt qua. ## Concept

<En>
**Capstone requirements checklist:**

A portfolio-grade capstone framework must include:
- [ ] A real target application (not a toy — use JSONPlaceholder, ReqRes, or Restful-Booker)
- [ ] API tests covering at least 3 endpoints (CRUD)
- [ ] UI tests covering at least 2 user flows
- [ ] Schema validation on all GET responses
- [ ] Positive and negative test cases
- [ ] Shared fixtures and data factory
- [ ] Allure report integration
- [ ] GitHub Actions CI
- [ ] Written test plan (Day 52)
- [ ] README with setup instructions

**Choosing a target application:**

| App | API | UI | Auth | Notes |
|-----|-----|-----|------|-------|
| JSONPlaceholder | ✓ | ✗ | ✗ | Best for API-only capstone |
| ReqRes.in | ✓ | ✗ | ✓ | Has login endpoint — good for auth testing |
| Restful-Booker | ✓ | ✓ | ✓ | Best full-stack capstone target |
| Swag Labs (Sauce Demo) | ✗ | ✓ | ✓ | Classic UI testing app |

**ReqRes.in** is a strong choice: it has user listing, user creation, login/auth, and pagination — enough to demonstrate all API testing skills with a real auth flow.

**Kickoff checklist (do these today):**
1. Create the project directory structure
2. Install all dependencies
3. Write `conftest.py` with base URL and session fixture
4. Write one passing API test
5. Verify `pytest tests/ -v` shows green
</En>
<Vi>
**Checklist yêu cầu capstone:**

Một framework capstone đạt chuẩn portfolio phải bao gồm:
- [ ] Ứng dụng mục tiêu thực sự (không phải đồ chơi — dùng JSONPlaceholder, ReqRes, hoặc Restful-Booker)

```python
# api/client.py
import requests

class ApiClient:
    def __init__(self, base_url: str, token: str | None = None) -> None:
        self._session = requests.Session()
        self._session.headers["Content-Type"] = "application/json"
        if token:
            self._session.headers["Authorization"] = f"Bearer {token}"
        self.base_url = base_url.rstrip("/")

    def get(self, path: str, **kwargs) -> requests.Response:
        return self._session.get(f"{self.base_url}{path}", **kwargs)

    def post(self, path: str, **kwargs) -> requests.Response:
        return self._session.post(f"{self.base_url}{path}", **kwargs)

    def put(self, path: str, **kwargs) -> requests.Response:
        return self._session.put(f"{self.base_url}{path}", **kwargs)

    def delete(self, path: str, **kwargs) -> requests.Response:
        return self._session.delete(f"{self.base_url}{path}", **kwargs)

    def patch(self, path: str, **kwargs) -> requests.Response:
        return self._session.patch(f"{self.base_url}{path}", **kwargs)
```

```python
from api.client import ApiClient

BASE_URL = "https://reqres.in/api"

@pytest.fixture(scope="session")
def api() -> ApiClient:
```

```python
# tests/api/test_users.py — first passing test
import pytest
import allure
from jsonschema import validate
from api.client import ApiClient

USER_SCHEMA = {
    "type": "object",
    "required": ["id", "email", "first_name", "last_name", "avatar"],
    "properties": {
        "id":         {"type": "integer"},
        "email":      {"type": "string"},
        "first_name": {"type": "string"},
        "last_name":  {"type": "string"},
        "avatar":     {"type": "string"},
    },
}

@allure.epic("User API")
@allure.feature("Users")
class TestUsers:

    @allure.story("Read")
    @allure.severity(allure.severity_level.CRITICAL)
    def test_get_user_by_id(self, api: ApiClient):
        with allure.step("GET /users/2"):
            response = api.get("/users/2")
        with allure.step("Verify 200 status"):
            assert response.status_code == 200
        with allure.step("Validate schema"):
            data = response.json()["data"]
            validate(instance=data, schema=USER_SCHEMA)

    @allure.story("Read")
    def test_list_users_page_1(self, api: ApiClient):
        with allure.step("GET /users?page=1"):
            response = api.get("/users", params={"page": 1})
        assert response.status_code == 200
        body = response.json()
        assert body["page"] == 1
        assert len(body["data"]) > 0

    @allure.story("Read")
    def test_user_not_found(self, api: ApiClient):
        response = api.get("/users/9999")
        assert response.status_code == 404
```
