## Intro

<En>
Every test has setup and teardown needs: open a browser, log in, create test data — then after the test, clean up. Without a structured way to handle these, you end up copying and pasting setup code into every test. pytest **fixtures** are the solution.

A fixture is a function that prepares something a test needs and cleans it up after. Once defined, any test function can request a fixture simply by naming it as a parameter. pytest injects it automatically — no import, no explicit call.

Fixtures can also have **scope**: function (fresh each test), module (shared across a file), session (shared across the entire run). Choosing the right scope is the difference between a fast test suite and a slow one.
</En>
<Vi>
Mỗi test đều có nhu cầu setup và teardown: mở trình duyệt, đăng nhập, tạo dữ liệu test — sau đó dọn dẹp sau khi test. Nếu không có cách có cấu trúc để xử lý những điều này, bạn sẽ phải sao chép và dán code setup vào mỗi test. **Fixture** của pytest là giải pháp.

Fixture là hàm chuẩn bị thứ gì đó mà test cần và dọn dẹp sau đó. Một khi đã định nghĩa, bất kỳ hàm test nào cũng có thể yêu cầu fixture chỉ bằng cách đặt tên nó làm tham số. pytest tự động inject nó — không cần import, không cần gọi tường minh.

Fixture cũng có **scope**: function (mới mỗi test), module (dùng chung trong file), session (dùng chung toàn bộ lần chạy). Chọn đúng scope là sự khác biệt giữa bộ test nhanh và bộ test chậm.
</Vi>

## Concept

<En>
**Basic fixture anatomy:**

```python
import pytest

@pytest.fixture
def my_fixture():
    # SETUP: runs before the test
    value = {"key": "value"}
    yield value          # ← the test receives this
    # TEARDOWN: runs after the test (even on failure)
    print("Cleaning up!")
```

Any test that declares `my_fixture` as a parameter gets the yielded value:

```python
def test_something(my_fixture):
    assert my_fixture["key"] == "value"  # passes
```

**Fixture scope — controls how often setup/teardown runs:**

| Scope | Runs | Use when |
|-------|------|---------|
| `"function"` | Every test (default) | Resource must be fresh per test |
| `"class"` | Once per test class | Class-level shared setup |
| `"module"` | Once per `.py` file | Expensive setup shared across a file |
| `"session"` | Once per entire run | Very expensive setup (DB connection, auth token) |

```python
@pytest.fixture(scope="session")
def browser_instance():
    """Launch browser once for all tests — much faster."""
    with sync_playwright() as p:
        browser = p.chromium.launch()
        yield browser
        browser.close()
```

**conftest.py — shared fixtures available to all tests:**
Any fixture defined in `conftest.py` is automatically available to all test files in the same directory and subdirectories — no import needed.

```
project/
├── conftest.py           ← fixtures here are globally available
├── tests/
│   ├── conftest.py       ← fixtures here are available to tests/ only
│   └── test_example.py
```

**Built-in pytest-playwright fixtures:**
pytest-playwright registers these for you:

```python
# These are all available out of the box:
def test_example(playwright, browser, context, page):
    pass  # each is injected automatically

# Override them in conftest.py to customise defaults:
@pytest.fixture(scope="session")
def browser_context_args(browser_context_args):
    return {**browser_context_args, "viewport": {"width": 1440, "height": 900}}
```

**Fixture composition — fixtures can use other fixtures:**
```python
@pytest.fixture
def authenticated_page(page):
    """Uses the built-in `page` fixture, adds login."""
    page.goto("https://practicesoftwaretesting.com/auth/login")
    page.get_by_label("Email").fill("customer@practicesoftwaretesting.com")
    page.get_by_label("Password").fill("welcome01")
    page.get_by_role("button", name="Login").click()
    page.wait_for_url("**/account")
    yield page
    # teardown: nothing needed — browser context is cleaned up by playwright fixture
```

**autouse fixtures — run automatically for every test:**
```python
@pytest.fixture(autouse=True)
def log_test_name(request):
    """Print test name before/after every test."""
    print(f"\n▶ Starting: {request.node.name}")
    yield
    print(f"✓ Finished: {request.node.name}")
```

**Hooks — plugin-style callbacks in conftest.py:**
```python
# conftest.py
def pytest_runtest_setup(item):
    """Called before each test setup."""
    print(f"\nSetting up: {item.name}")

def pytest_runtest_teardown(item, nextitem):
    """Called after each test teardown."""
    print(f"Tearing down: {item.name}")

# Mark failed tests for screenshot capture
@pytest.hookimpl(hookwrapper=True)
def pytest_runtest_makereport(item, call):
    outcome = yield
    rep = outcome.get_result()
    setattr(item, "rep_" + rep.when, rep)
```
</En>
<Vi>
**Cấu trúc fixture cơ bản:**

```python
import pytest

@pytest.fixture
def my_fixture():
    # SETUP: chạy trước test
    value = {"key": "value"}
    yield value          # ← test nhận giá trị này
    # TEARDOWN: chạy sau test (kể cả khi thất bại)
    print("Dọn dẹp!")
```

**Scope của fixture:**

| Scope | Chạy | Dùng khi |
|-------|------|---------|
| `"function"` | Mỗi test (mặc định) | Tài nguyên phải mới mỗi test |
| `"class"` | Một lần mỗi class | Setup dùng chung trong class |
| `"module"` | Một lần mỗi file .py | Setup tốn kém dùng chung trong file |
| `"session"` | Một lần toàn bộ lần chạy | Setup rất tốn kém (kết nối DB, token auth) |

**conftest.py — fixture dùng chung:**
Fixture trong `conftest.py` tự động có sẵn cho tất cả file test trong cùng thư mục và thư mục con — không cần import.

**Composition fixture:**
```python
@pytest.fixture
def authenticated_page(page):
    """Dùng fixture `page` tích hợp sẵn, thêm bước đăng nhập."""
    page.goto("https://practicesoftwaretesting.com/auth/login")
    page.get_by_label("Email").fill("customer@practicesoftwaretesting.com")
    page.get_by_label("Password").fill("welcome01")
    page.get_by_role("button", name="Login").click()
    page.wait_for_url("**/account")
    yield page
```

```python
# conftest.py
import pytest
from playwright.sync_api import Page

BASE_URL = "https://practicesoftwaretesting.com"
VALID_CREDS = {
    "email": "customer@practicesoftwaretesting.com",
    "password": "welcome01",
}

@pytest.fixture
def authenticated_page(page: Page) -> Page:
    """
    Provides an already-logged-in page.
    Scope: function (fresh login for each test — safest default).
    """
    page.goto(f"{BASE_URL}/auth/login")
    page.get_by_label("Email").fill(VALID_CREDS["email"])
    page.get_by_label("Password").fill(VALID_CREDS["password"])
    page.get_by_role("button", name="Login").click()
    page.wait_for_url("**/account")
    yield page
    # No teardown needed — pytest-playwright cleans up the context

@pytest.fixture
def test_credentials() -> dict:
    """Provides test credentials as a dict."""
    return VALID_CREDS.copy()
```

```python
# tests/test_fixtures_demo.py
# Run with: pytest tests/test_fixtures_demo.py -v
from playwright.sync_api import Page, expect

BASE = "https://practicesoftwaretesting.com"

def test_login_manually(page: Page, test_credentials: dict):
    """Uses test_credentials fixture — no hard-coded passwords in test."""
    page.goto(f"{BASE}/auth/login")
    page.get_by_label("Email").fill(test_credentials["email"])
    page.get_by_label("Password").fill(test_credentials["password"])
    page.get_by_role("button", name="Login").click()
    expect(page).to_have_url(f"{BASE}/account")

def test_account_page_heading(authenticated_page: Page):
    """Uses authenticated_page — login is already done."""
    heading = authenticated_page.get_by_role("heading", name="My account")
    expect(heading).to_be_visible()

def test_profile_section_visible(authenticated_page: Page):
    """Another test using authenticated_page — independent login."""
    profile = authenticated_page.get_by_role("link", name="Profile")
    expect(profile).to_be_visible()

def test_sign_out_works(authenticated_page: Page):
    """Sign out should redirect back to home or login."""
    sign_out = authenticated_page.get_by_role("link", name="Sign out")
    sign_out.click()
    # After logout, should not be on account page
    assert "/account" not in authenticated_page.url

# Run: pytest tests/test_fixtures_demo.py -v
# All three *_account tests will each perform their own login
# (function scope) but the page is already ready for them.
```
