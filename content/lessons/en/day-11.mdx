## Intro

<En>
Operators are the building blocks of any assertion. When you write `assert response.status_code == 200`, you are using a comparison operator. Understanding Python's operators — especially the tricky distinctions between `==` and `is`, and between `and`/`or`/`not` — prevents a whole class of subtle test bugs.
</En>
<Vi>
Toán tử là nền tảng của mọi assertion. Khi bạn viết `assert response.status_code == 200`, bạn đang dùng toán tử so sánh. Hiểu các toán tử của Python — đặc biệt sự khác biệt tinh tế giữa `==` và `is`, và giữa `and`/`or`/`not` — ngăn chặn cả một lớp lỗi test tinh vi.
</Vi>

## Concept

<En>
**Comparison operators:**

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | Equal value | `status == 200` |
| `!=` | Not equal | `error != None` |
| `<`, `>` | Less / greater | `count > 0` |
| `<=`, `>=` | Less or equal / greater or equal | `response_time <= 500` |
| `is` | Same object identity | `x is None` |
| `is not` | Different object identity | `x is not None` |
| `in` | Membership | `"admin" in roles` |
| `not in` | Non-membership | `"banned" not in roles` |

**Critical rule — `==` vs `is`:**
- `==` compares **value**. Use for numbers, strings, booleans, lists.
- `is` compares **identity** (same object in memory). Use **only** for `None`, `True`, `False`.
- Never write `x == None`. Always write `x is None` or `x is not None`.

**Logical operators:**

| Operator | Meaning | Short-circuits at |
|----------|---------|-------------------|
| `and` | Both must be true | First `False` |
| `or` | At least one true | First `True` |
| `not` | Invert truth | — |

**Chained comparisons** — Python allows `0 < count < 100`, which is cleaner than `count > 0 and count < 100`.
</En>
<Vi>
**Toán tử so sánh:**

| Toán tử | Ý nghĩa | Ví dụ |
|----------|---------|---------|
| `==` | Giá trị bằng nhau | `status == 200` |
| `!=` | Không bằng nhau | `error != None` |
| `<`, `>` | Nhỏ hơn / lớn hơn | `count > 0` |
| `<=`, `>=` | Nhỏ hơn hoặc bằng / lớn hơn hoặc bằng | `response_time <= 500` |
| `is` | Cùng đối tượng (identity) | `x is None` |
| `is not` | Đối tượng khác nhau | `x is not None` |
| `in` | Thành viên | `"admin" in roles` |
| `not in` | Không phải thành viên | `"banned" not in roles` |

**Quy tắc quan trọng — `==` vs `is`:**
- `==` so sánh **giá trị**. Dùng cho số, chuỗi, boolean, list.
- `is` so sánh **identity** (cùng đối tượng trong bộ nhớ). Chỉ dùng cho `None`, `True`, `False`.
- Đừng bao giờ viết `x == None`. Luôn viết `x is None` hoặc `x is not None`.

**Toán tử logic:**

| Toán tử | Ý nghĩa | Ngắn mạch tại |
|----------|---------|-------------------|
| `and` | Cả hai phải đúng | `False` đầu tiên |
| `or` | Ít nhất một đúng | `True` đầu tiên |
| `not` | Đảo ngược | — |
</Vi>

## Code / Demo

**Pattern 1 — Comparison operators: `==`, `!=`, `<`, `<=`, `>=`**

<En>These six operators form the foundation of every assertion. They compare values and always return `True` or `False`.</En>
<Vi>Sáu toán tử này là nền tảng của mọi assertion. Chúng so sánh giá trị và luôn trả về `True` hoặc `False`.</Vi>

<CodePlayground code={`
status_code = 200
response_time_ms = 342

assert status_code == 200,       "status must be 200"
assert status_code != 404,       "should not be 404"
assert response_time_ms <= 500,  "response too slow"
assert response_time_ms >= 100,  "response unrealistically fast"
assert response_time_ms > 0
assert status_code < 300

print(f"status_code={status_code}, response_time={response_time_ms}ms")
print("Pattern 1 ok — comparison operators")
`} />

**Pattern 2 — Membership and None checks: `in`, `not in`, `is`, `is not`**

<En>Use `in`/`not in` to test membership in lists, strings, or dicts. Use `is None` / `is not None` — never `== None` — because `is` checks object identity, which is correct and PEP 8-compliant.</En>
<Vi>Dùng `in`/`not in` để kiểm tra thành viên trong list, string hoặc dict. Dùng `is None` / `is not None` — không bao giờ dùng `== None` — vì `is` kiểm tra identity đối tượng, đúng và tuân thủ PEP 8.</Vi>

<CodePlayground code={`
roles = ["viewer", "editor"]
error = None
data = {"user": "alice"}
message = "User created successfully"

# Membership
assert "editor" in roles
assert "admin" not in roles
assert "created" in message.lower()

# None checks — always 'is', never '=='
assert error is None
assert data is not None
token = data.get("token")   # key doesn't exist → returns None
assert token is None

print(f"Roles: {roles}")
print(f"error is None: {error is None}")
print("Pattern 2 ok — membership and None checks")
`} />

**Pattern 3 — Chained comparisons**

<En>Python lets you chain comparisons like `0 < count < 100`. This is cleaner than writing `count > 0 and count < 100` and reads like mathematical notation.</En>
<Vi>Python cho phép bạn viết so sánh chuỗi như `0 < count < 100`. Cách này gọn hơn `count > 0 and count < 100` và đọc như ký hiệu toán học.</Vi>

<CodePlayground code={`
count = 5
status_code = 201
response_time_ms = 342

# Chained comparisons — Pythonic and readable
assert 0 < count < 100,              "count out of range"
assert 200 <= status_code < 300,     f"Expected 2xx, got {status_code}"
assert 100 <= response_time_ms <= 500, "response time out of acceptable range"

# Equivalent but less readable — avoid this style
assert count > 0 and count < 100    # same result, harder to read

print(f"count={count} ✓")
print(f"status={status_code} ✓")
print(f"response_time={response_time_ms}ms ✓")
print("Pattern 3 ok — chained comparisons")
`} />

**Pattern 4 — Logical operators: `and`, `or`, `not`**

<En>`and` requires both sides to be truthy. `or` passes if either side is truthy. `not` inverts a boolean. These combine multiple conditions into a single assertion.</En>
<Vi>`and` yêu cầu cả hai vế đều truthy. `or` thành công nếu một trong hai vế truthy. `not` đảo ngược boolean. Chúng kết hợp nhiều điều kiện thành một assertion duy nhất.</Vi>

<CodePlayground code={`
is_authenticated = True
has_permission   = True
is_admin         = False
is_superuser     = True

# and — both must be true
assert is_authenticated and has_permission, "Must be authenticated AND have permission"

# or — at least one must be true
assert is_admin or is_superuser, "Must be admin or superuser"

# not — invert a condition
assert not is_admin, "Regular user should not be admin"

# Combining: real-world assertion
status_code = 200
body = {"id": 42}
assert status_code == 200 and body is not None, "Expected 200 with a body"

print(f"authenticated={is_authenticated}, superuser={is_superuser}")
print("Pattern 4 ok — logical operators")
`} />
