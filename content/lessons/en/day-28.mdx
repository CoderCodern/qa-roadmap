## Intro

<En>
Real-world web apps are rarely single-page — they open new tabs, trigger popup dialogs, embed content in iframes, and expect you to handle all of them. If your test clicks a "Share" button that opens a new tab, your test needs to catch that new tab. If a payment widget is inside an iframe, you need to switch into it before you can type a card number.

Playwright makes handling these complex scenarios surprisingly clean — but you need to know the right patterns. This session covers the three most common multi-context scenarios: new tabs, popups, and iframes.
</En>
<Vi>
Ứng dụng web thực tế hiếm khi là một trang đơn — chúng mở tab mới, kích hoạt hộp thoại popup, nhúng nội dung trong iframe, và yêu cầu bạn xử lý tất cả chúng. Nếu test của bạn nhấp vào nút "Chia sẻ" mở tab mới, test của bạn cần bắt tab mới đó. Nếu widget thanh toán nằm trong iframe, bạn cần chuyển vào nó trước khi có thể gõ số thẻ.

Playwright làm cho việc xử lý các tình huống phức tạp này trở nên rõ ràng đến ngạc nhiên — nhưng bạn cần biết các pattern đúng.
</Vi>

## Concept

<En>
**Handling new tabs:**
When a click opens a new tab (`target="_blank"`), use `context.expect_page()` to capture it:

```python
# Pattern: wrap the click in expect_page to catch the new tab
with context.expect_page() as new_page_info:
    page.get_by_role("link", name="Open in new tab").click()

new_tab = new_page_info.value
# Always wait for load state before interacting with the new tab.
# 'load' waits for the load event; 'networkidle' waits until there
# are no more than 0 network connections for 500ms.
new_tab.wait_for_load_state()
print(f"New tab URL: {new_tab.url}")
```

> **Note:** `wait_for_load_state()` defaults to `'load'`. For pages with heavy async data fetching, use `new_tab.wait_for_load_state('networkidle')` to ensure all XHR/fetch requests have settled before making assertions.

**Handling popup dialogs:**
JavaScript `alert()`, `confirm()`, and `prompt()` are all dialog events:

```python
# Dismiss/accept a dialog before triggering it
def handle_dialog(dialog):
    print(f"Dialog type   : {dialog.type}")     # 'alert', 'confirm', or 'prompt'
    print(f"Dialog message: {dialog.message}")
    dialog.accept()     # click OK (or for prompt: dialog.accept("typed value"))
    # dialog.dismiss()  # click Cancel

page.on("dialog", handle_dialog)
page.get_by_role("button", name="Delete").click()
# If Delete triggers confirm("Are you sure?"), handle_dialog accepts it
```

**When are iframes commonly used?**
Iframes appear in production apps for sandboxing third-party content safely:
- **Payment widgets** — Stripe, PayPal, Adyen embed card forms in iframes so the merchant's JS cannot access card numbers
- **Embedded maps** — Google Maps, OpenStreetMap iframes on contact pages
- **Social login** — some OAuth flows use popup-like iframes
- **Rich text editors** — TinyMCE, Quill render their editable area in an iframe (which lets them control the document's CSS scope)
- **CAPTCHA** — reCAPTCHA v2 checkbox is inside an iframe

Whenever you see "element not found" in a test despite the element being visible, check whether it lives inside an iframe.

**Handling iframes:**
An iframe is a separate document embedded in the page. You must get a reference to the frame before interacting with elements inside it.

```python
# Method 1: frame_locator() — recommended modern approach
# Returns a FrameLocator — use it exactly like a page for chaining locators
frame = page.frame_locator("iframe.payment-widget")
frame.locator("#card-number").fill("4111111111111111")
frame.get_by_label("CVV").fill("123")
frame.get_by_role("button", name="Pay").click()

# Method 2: content_frame() — older approach for when you have a Locator
# Useful if you already have an element reference and need to enter it
frame_element = page.locator("iframe.payment-widget")
frame = frame_element.content_frame()  # converts Locator → Frame
frame.locator("#card-number").fill("4111111111111111")

# Method 3: page.frame() — for named iframes (less common)
frame = page.frame("frame-name")       # by name attribute
frame = page.frame(url="https://payment.example.com/widget")  # by URL pattern
```

**Difference between `frame_locator()` and `content_frame()`:**

| | `page.frame_locator(selector)` | `locator.content_frame()` |
|---|---|---|
| Input | CSS/XPath selector string | An existing `Locator` object |
| Returns | `FrameLocator` (locator-style) | `Frame` (frame-style) |
| Auto-wait | Yes — like a regular locator | Yes |
| Best for | When you know the iframe selector upfront | When you already hold a Locator reference |

Both approaches work — `frame_locator()` is preferred for its cleaner chaining syntax.

**Multiple pages in a context — full control:**
```python
# Get all open pages
all_pages = context.pages
print(f"Open tabs: {len(all_pages)}")

# Switch to a specific page by index
second_tab = context.pages[1]
second_tab.bring_to_front()  # gives it visual focus in the browser

# Even without bring_to_front(), you can still call page methods
# (Playwright controls tabs programmatically, not via UI clicks)
second_tab.get_by_role("button", name="Confirm").click()

# Close a specific tab
second_tab.close()
assert len(context.pages) == 1  # verify only original tab remains
```

**Browser popup windows (not JavaScript dialogs):**
Browser-level popups opened by `window.open()` are new pages in the context:

```python
with context.expect_page() as popup_info:
    page.get_by_role("button", name="Open popup").click()

popup = popup_info.value
popup.wait_for_load_state()
# Interact with the popup
popup.get_by_role("button", name="Confirm").click()
popup.close()
```
</En>
<Vi>
**Xử lý tab mới:**
```python
with context.expect_page() as new_page_info:
    page.get_by_role("link", name="Mở tab mới").click()

new_tab = new_page_info.value
# Luôn đợi trang load xong trước khi tương tác
new_tab.wait_for_load_state()
print(f"URL tab mới: {new_tab.url}")
```

> **Lưu ý:** `wait_for_load_state()` mặc định là `'load'`. Với các trang fetch nhiều dữ liệu async, dùng `wait_for_load_state('networkidle')` để đảm bảo tất cả request đã hoàn thành.

**Xử lý hộp thoại popup:**
```python
def handle_dialog(dialog):
    print(f"Loại: {dialog.type}")      # 'alert', 'confirm', hoặc 'prompt'
    print(f"Thông báo: {dialog.message}")
    dialog.accept()

page.on("dialog", handle_dialog)
page.get_by_role("button", name="Xóa").click()
```

**Khi nào iframe được dùng?**
- Widget thanh toán (Stripe, PayPal)
- Bản đồ nhúng (Google Maps)
- Đăng nhập mạng xã hội
- Trình soạn thảo văn bản phong phú (TinyMCE, Quill)
- CAPTCHA (reCAPTCHA v2)

**Xử lý iframe:**
```python
# Phương pháp 1: frame_locator() — cách tiếp cận hiện đại được khuyến nghị
frame = page.frame_locator("iframe.payment-widget")
frame.locator("#card-number").fill("4111111111111111")
frame.get_by_role("button", name="Pay").click()

# Phương pháp 2: content_frame() — khi bạn đã có Locator
frame_element = page.locator("iframe.payment-widget")
frame = frame_element.content_frame()
frame.locator("#card-number").fill("4111111111111111")
```

```python
# demo_new_tab.py
# Run with: python demo_new_tab.py
from playwright.sync_api import sync_playwright, expect

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    context = browser.new_context()
    page = context.new_page()

    # Navigate to a page that has a link opening in a new tab
    # Using practicesoftwaretesting.com — "Lab" opens in new tab
    page.goto("https://practicesoftwaretesting.com")

    print(f"Current pages open: {len(context.pages)}")  # Output: Current pages open: 1

    # The Labs/Blog links open in new tabs — capture the new tab
    # with expect_page() as a context manager.
    #
    # NOTE about the evaluate() approach below:
    # window.open() via evaluate() simulates a new-tab open without needing
    # a real target="_blank" link on the page. This is useful for demos and
    # sites where you cannot easily find a link that opens a new tab.
    # In production tests, prefer clicking the actual link that opens the tab
    # so you are testing the real user flow:
    #   page.get_by_role("link", name="GitHub").click()  # if it has target=_blank
    with context.expect_page() as new_page_info:
        # Simulates what a target="_blank" link does
        page.evaluate("window.open('https://playwright.dev', '_blank')")

    new_tab = new_page_info.value
    new_tab.wait_for_load_state()

    print(f"New tab URL: {new_tab.url}")          # Output: New tab URL: https://playwright.dev/
    print(f"Total pages open: {len(context.pages)}")  # Output: Total pages open: 2

    # Interact with the new tab
    expect(new_tab).to_have_url("https://playwright.dev/")
    print(f"New tab title: {new_tab.title()}")    # Output: New tab title: Playwright

    # Close the new tab and return to original
    new_tab.close()
    print(f"Pages after close: {len(context.pages)}")  # Output: Pages after close: 1
    print(f"Back on: {page.url}")                      # Output: Back on: https://practicesoftwaretesting.com/

    context.close()
    browser.close()
```

**Phần 2 — Xử lý dialog: alert, confirm và prompt**

</Vi>

```python
# demo_dialogs.py
# Demonstrates handling alert(), confirm(), and prompt() dialogs
from playwright.sync_api import sync_playwright, Dialog

dialogs_seen = []

def capture_dialog(dialog: Dialog):
    """Handler called when any dialog appears."""
    print(f"  Dialog type   : {dialog.type}")
    print(f"  Dialog message: {dialog.message}")
    dialogs_seen.append({"type": dialog.type, "message": dialog.message})

    if dialog.type == "alert":
        # alert() has one button: OK.
        # accept() and dismiss() both close it — accept() is conventional.
        dialog.accept()
    elif dialog.type == "confirm":
        # confirm() has two buttons: OK and Cancel.
        # accept() → confirm() returns True in JavaScript.
        # dismiss() → confirm() returns False in JavaScript.
        dialog.accept()
    elif dialog.type == "prompt":
        # prompt() has a text input + OK/Cancel.
        # accept("value") types the string and clicks OK.
        # dismiss() clicks Cancel; the prompt returns null.
        dialog.accept("My answer")

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()

    # Register the dialog handler BEFORE triggering the dialog
    page.on("dialog", capture_dialog)

    page.goto("https://example.com")

    # Trigger dialogs via JavaScript (simulating what a real app might do)
    print("Triggering alert():")
    page.evaluate("alert('Hello from alert!')")
    # Expected output:
    #   Dialog type   : alert
    #   Dialog message: Hello from alert!

    print("\nTriggering confirm():")
    result = page.evaluate("confirm('Do you want to proceed?')")
    print(f"  confirm() returned: {result}")
    # Expected output:
    #   Dialog type   : confirm
    #   Dialog message: Do you want to proceed?
    #   confirm() returned: True   ← True because we called dialog.accept()

    print("\nTriggering prompt():")
    answer = page.evaluate("prompt('What is your name?', 'default')")
    print(f"  prompt() returned: {answer}")
    # Expected output:
    #   Dialog type   : prompt
    #   Dialog message: What is your name?
    #   prompt() returned: My answer   ← the string passed to dialog.accept()

    print(f"\nTotal dialogs handled: {len(dialogs_seen)}")
    # Expected output: Total dialogs handled: 3
    browser.close()
```

**Phần 3 — Tương tác với iframe**

```python
# demo_iframe.py
# Uses a site with an embedded iframe (common in payment widgets)
# For demo purposes, we'll use w3schools which has iframes
from playwright.sync_api import sync_playwright, expect

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()

    # Navigate to a page with an iframe
    # This site has a demo iframe with form elements
    page.goto("https://the-internet.herokuapp.com/iframe")
    page.wait_for_load_state("networkidle")

    # Get a reference to the iframe using frame_locator().
    # frame_locator() returns a FrameLocator — an object you use like a page
    # to find elements INSIDE the iframe document.
    iframe = page.frame_locator("#mce_0_ifr")

    # Interact with content inside the iframe
    body = iframe.locator("body")
    body.click()  # click to give the iframe body keyboard focus

    # Control+A selects ALL text currently inside the focused iframe body.
    # This is equivalent to the user pressing Ctrl+A in the editor — it
    # highlights everything so the next keyboard.type() replaces it entirely.
    page.keyboard.press("Control+A")
    page.keyboard.type("This text was typed inside an iframe!")

    print(f"Iframe body text: {body.text_content()}")
    # Expected output: Iframe body text: This text was typed inside an iframe!

    browser.close()
    print("Iframe interaction complete!")
```
