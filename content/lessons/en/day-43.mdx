## Intro

<En>
Most real APIs require authentication. The most common pattern is Bearer token authentication: a client logs in, receives a token, and includes that token in every subsequent request. Testing authenticated endpoints means testing both the happy path (valid token) and the error cases (missing token, expired token, wrong role). Today you learn the patterns for handling auth in your API test suite.
</En>
<Vi>
Hầu hết các API thực đều yêu cầu xác thực. Mẫu phổ biến nhất là xác thực Bearer token: client đăng nhập, nhận token và đưa token đó vào mọi request tiếp theo. Kiểm thử các endpoint cần xác thực có nghĩa là kiểm thử cả happy path (token hợp lệ) và các trường hợp lỗi (thiếu token, token hết hạn, sai role). Hôm nay bạn học các mẫu xử lý auth trong bộ API test.
</Vi>

## Concept

<En>
**Authentication types you'll encounter:**

| Type | How it works | Where the token goes |
|------|-------------|---------------------|
| Bearer / JWT | Login returns a token | `Authorization: Bearer <token>` header |
| API Key | Static key per client | `X-API-Key: <key>` header or query param |
| Basic Auth | Username:password base64 encoded | `Authorization: Basic <base64>` header |
| Session Cookie | Login sets a cookie | Cookie header (managed by browser/session) |

**JWT (JSON Web Token) structure:**
A JWT is three base64-encoded parts separated by dots:
- **Header:** algorithm and token type (e.g. `{"alg": "HS256", "typ": "JWT"}`)
- **Payload:** claims — user id, role, issued-at, expiry
- **Signature:** server-signed hash that proves the token was not tampered with

Example JWT: `eyJhbGciOiJIUzI1NiJ9.eyJ1c2VySWQiOjF9.abc123`

**Testing auth patterns:**

**1. Test that a valid token allows access:**
```python
response = client.get("/api/protected", headers={"Authorization": f"Bearer {token}"})
assert response.status_code == 200
```

**2. Test that no token returns 401:**
```python
response = requests.get("/api/protected")  # no auth header
assert response.status_code == 401
```

**3. Test that a wrong token also returns 401:**
```python
response = requests.get("/api/protected", headers={"Authorization": "Bearer invalid.token"})
assert response.status_code == 401
```

**4. Test that a valid token with wrong role returns 403:**
```python
viewer_token = login("viewer@example.com", "password")
response = client.delete("/api/users/1", headers={"Authorization": f"Bearer {viewer_token}"})
assert response.status_code == 403
```

Testing both "no token" AND "wrong token" matters: some APIs accidentally accept any non-empty Authorization header, and you want to catch that.

**Pytest fixture for authenticated sessions:**
```python
@pytest.fixture(scope="session")
def admin_session(base_url: str) -> requests.Session:
    session = requests.Session()
    response = session.post(f"{base_url}/auth/login", json={
        "email": os.environ["ADMIN_EMAIL"],
        "password": os.environ["ADMIN_PASSWORD"],
    })
    assert response.status_code == 200
    token = response.json()["access_token"]
    session.headers["Authorization"] = f"Bearer {token}"
    yield session
    session.post(f"{base_url}/auth/logout")
```

**Credentials must never be hardcoded.** Use environment variables or a `.env` file loaded with `python-dotenv`. This prevents credentials from being committed to version control.

**Basic Auth encoding:**
```python
import base64

credentials = "admin:secretpassword"
encoded = base64.b64encode(credentials.encode()).decode()
headers = {"Authorization": f"Basic {encoded}"}
```
</En>
<Vi>
**Các loại xác thực bạn sẽ gặp:**

| Loại | Cách hoạt động | Token đặt ở đâu |
|------|-------------|---------------------|
| Bearer / JWT | Đăng nhập trả về token | Header `Authorization: Bearer <token>` |
| API Key | Khóa tĩnh cho mỗi client | Header `X-API-Key: <key>` hoặc query param |
| Basic Auth | Username:password được base64 mã hoá | Header `Authorization: Basic <base64>` |
| Session Cookie | Đăng nhập đặt cookie | Cookie header (trình duyệt/session quản lý) |

**Cấu trúc JWT (JSON Web Token):**
JWT gồm ba phần được base64 mã hoá, ngăn cách bởi dấu chấm:
- **Header:** thuật toán và loại token (ví dụ `{"alg": "HS256", "typ": "JWT"}`)
- **Payload:** claims — user id, role, thời điểm cấp, hết hạn
- **Signature:** hash được server ký xác nhận token không bị giả mạo

**Mẫu kiểm thử auth:**

**1. Kiểm tra token hợp lệ cho phép truy cập:**
```python
response = client.get("/api/protected", headers={"Authorization": f"Bearer {token}"})
assert response.status_code == 200
```

**2. Kiểm tra không có token trả về 401:**
```python
response = requests.get("/api/protected")
assert response.status_code == 401
```

**3. Kiểm tra token sai cũng trả về 401:**
```python
response = requests.get("/api/protected", headers={"Authorization": "Bearer invalid.token"})
assert response.status_code == 401
```

**4. Kiểm tra token hợp lệ nhưng sai role trả về 403:**
```python
response = viewer_client.delete("/api/users/1")
assert response.status_code == 403
```

Kiểm tra cả "không có token" VÀ "token sai" rất quan trọng: một số API vô tình chấp nhận bất kỳ Authorization header nào khác rỗng, và bạn muốn bắt lỗi đó.

**Credentials không bao giờ được hardcode.** Dùng biến môi trường hoặc file `.env` tải bởi `python-dotenv`. Điều này ngăn credentials bị commit vào version control.
</Vi>

<Vi>

**Phần 1 — Xây dựng các hàm trợ giúp auth và mô phỏng luồng Bearer token**

</Vi>

```python
import requests
import base64

BASE_URL = "https://jsonplaceholder.typicode.com"

# --- Helper: Bearer token ---
def make_auth_headers(token: str) -> dict:
    return {"Authorization": f"Bearer {token}"}

def make_authenticated_session(token: str) -> requests.Session:
    session = requests.Session()
    session.headers.update(make_auth_headers(token))
    return session

# Simulated: in a real test you'd POST to /auth/login to get this token
fake_token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.test"
auth_session = make_authenticated_session(fake_token)

response = auth_session.get(f"{BASE_URL}/posts/1")
print(f"Auth header sent: {response.request.headers.get('Authorization')}")
print(f"Status: {response.status_code}")

# --- Helper: Basic Auth ---
def make_basic_auth_header(username: str, password: str) -> dict:
    credentials = f"{username}:{password}"
    encoded = base64.b64encode(credentials.encode()).decode()
    return {"Authorization": f"Basic {encoded}"}

basic_headers = make_basic_auth_header("admin", "secret")
print(f"Basic auth header: {basic_headers['Authorization'][:30]}...")

# --- Helper: API Key ---
def make_api_key_session(api_key: str) -> requests.Session:
    session = requests.Session()
    session.headers["X-API-Key"] = api_key
    return session
```
