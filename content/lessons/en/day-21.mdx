## Concept

<En>
**Project structure:**
```
calculator/
├── calculator.py       # core logic module
├── cli.py              # command-line interface
└── tests/
    ├── __init__.py
    └── test_calculator.py  # pytest test file
```

**pytest basics:**
- Any file named `test_*.py` or `*_test.py` is discovered automatically.
- Any function named `test_*` is a test.
- Use `assert` for assertions — pytest rewrites them for readable failure output.
- Run all tests: `pytest tests/`
- Run with verbose output: `pytest -v`
- Run a single test: `pytest tests/test_calculator.py::test_add`

**What makes a good pytest test:**
- Clear name describing what's being tested (`test_divide_raises_on_zero`)
- AAA pattern: Arrange, Act, Assert
- One logical concept per test
- `pytest.raises(ExceptionType)` to assert that an exception is raised

**Installing pytest:**
```bash
pip install pytest
```
</En>

## Code / Demo

```python
# calculator.py — the core module

class CalculatorError(Exception):
    pass

def add(a: float, b: float) -> float:
    return a + b

def subtract(a: float, b: float) -> float:
    return a - b

def multiply(a: float, b: float) -> float:
    return a * b

def divide(a: float, b: float) -> float:
    if b == 0:
        raise CalculatorError("Division by zero is not allowed")
    return a / b

def calculate(operation: str, a: float, b: float) -> float:
    ops = {
        "+": add,
        "-": subtract,
        "*": multiply,
        "/": divide,
    }
    if operation not in ops:
        raise CalculatorError(f"Unknown operation: '{operation}'")
    return ops[operation](a, b)
```

```python
# tests/test_calculator.py — the pytest test file

import pytest
from calculator import add, subtract, multiply, divide, calculate, CalculatorError

# --- add ---
def test_add_positive_numbers():
    assert add(2, 3) == 5

def test_add_negative_numbers():
    assert add(-1, -4) == -5

def test_add_floats():
    assert add(0.1, 0.2) == pytest.approx(0.3)  # float precision!

# --- subtract ---
def test_subtract():
    assert subtract(10, 4) == 6

def test_subtract_gives_negative():
    assert subtract(3, 10) == -7

# --- multiply ---
def test_multiply():
    assert multiply(6, 7) == 42

def test_multiply_by_zero():
    assert multiply(100, 0) == 0

# --- divide ---
def test_divide():
    assert divide(10, 2) == 5.0

def test_divide_raises_on_zero():
    with pytest.raises(CalculatorError, match="Division by zero"):
        divide(10, 0)

# --- calculate dispatcher ---
def test_calculate_addition():
    assert calculate("+", 3, 4) == 7

def test_calculate_unknown_operation_raises():
    with pytest.raises(CalculatorError, match="Unknown operation"):
        calculate("^", 2, 3)
```
